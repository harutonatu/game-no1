## 1. 決まったこと

| 項目 | 決定 |
|---|---|
| 核 | 街が育つ楽しさ |
| 入れるしくみ | お金・住みやすさ・ときどき起こるできごと・環境問題・仕事（5 つすべて） |
| 住む場所（4 種類・2 軸） | ユーザー決定：**人口密度**と**税収（地価）**の 2 軸。人口密度が高い＝アパート・マンション、地価が高い＝住宅地・高級住宅地。平屋の長屋は除く。PM の仮の置き方：アパート（密度 高・地価 低め）・マンション（密度 高・地価 高め）・住宅地（密度 低・地価 中）・高級住宅地（密度 低・地価 いちばん高い） |
| 仕事場（3 種類） | 第一次産業は**陸・山・海で 1 種類ずつ**（PM の仮：陸＝はたけ、山＝林業（木を切る）、海＝漁港）・第二次産業（こうば。よごれが出る）・第三次産業（おみせ・会社など）。ユーザー「仕事場はOKです」 |
| 移動 | 道路（車）と電車。**道路は交差点で渋滞しやすい**（車が多いほど・交差点が多いほど混む。混むと住みやすさ・仕事への通いが下がり、よごれも出る）。**電車は渋滞しない**。**駅は無し**（ユーザー「駅の概念は外してもいい」。PM の仮：線路が通るマスのそばの地区どうしが早くつながる） |
| 地図の広さ | ユーザー「マップが狭い！…ただの町内会以下に見える」→ 地図を大きくする（PM の仮：64×64 マスくらい。2 本指で拡大・縮小、1 本指で動かす。広げると街全体、寄ると 1 マスずつ置ける。大きさは見本で決める） |
| まねないこと | 初代シムシティ／Micropolis の名前・絵・画面の配置・決まりの写し・コードは使わない。オリジナルの決まり・絵・名前で作る |

## 3. 5 つのしくみのたたき台（PM。数値はあとで自動プレイで測る）

- **お金**：税（すむ人・しごと・おみせから少しずつ）が入り、置くのにお金がかかる。足りないと置けない。借金で負けにはしない（やり直せる）。
- **住みやすさ**：マスごとの「すみやすさ」。みち・おみせ・こうえん・しごとばへの近さで上がり、よごれ・さわがしさで下がる。低いと人が出ていく。
- **仕事**：しごとば（はたけ・こうば・おみせ）があると人が来る。すむ人に対して仕事が足りないと人が減り、仕事が多すぎるとすむ所が足りない。
- **環境問題**：こうばの近くはよごれる。こうえん・木で減る。よごれは住みやすさを下げる。
- **ときどき起こること**：大雨（みちが通れない）・火事（近くの消防で消える）・おまつり（人が増える）など。こわしすぎない・責めない。
