### レビューの傾向（出典つき、複数アプリの混在）
- 事実に基づいて：最大の不満は広告の量と長さ。「クリアごとに広告」「45秒〜1分の広告」「広告なしと書いてあるのに長い広告」「広告なし課金後も広告が出る／購入確認の表示が出続ける」（[justuseapp のレビュー集](https://justuseapp.com/en/app/1593801388/water-sort-puzzle-sorting-game/reviews)、[App Store](https://apps.apple.com/us/app/water-sort-color-puzzle-game/id1568411880?uo=4)）。
- 日本語でも同じ：「1面ごとに広告」「広告が閉じられない」「マナーモードでも音が出る」。一方「注ぐ音が心地よい」「指1本で簡単」「無課金で進められる」という好意的な声もある（[appmatch.jp](https://appmatch.jp/1597897013-4)）。
- 単調さ：「500面やっても各面が同じに見える」「ある難しさから先は上がらない」「色が違うだけの面が多い」（justuseapp、App Store の同系結果）。
- 難しすぎる：終盤に急に難しい面がある、詰んで広告で救済を求められる（appmatch.jp）。
- 好まれるのは「広告が少ない」「毎回広告で止まらない」点（上と同じ出典）。

以下は推測です：色水ソートの不満は「広告」「単調」の2つに集約される。他の不満（詰む・難しすぎ）は、広告で救済させる作りとセットで起きている。

## 2. いろびんの把握（コードと契約）

事実に基づいて（docs/irobin-contract.md と games/irobin/）：
- 瓶は1本4段。色は面で2〜9色、空き瓶は2本。瓶をタップして注ぐ（§1.1、§3.2）。
- 色ごとに「動物のお客さん」の注文があり、そろった瓶を届けると瓶が消える。見えるお客さんは2人（`ORDER_SLOTS = 2`）。注文の順が考えどころ（§1.1、§17）。
- 布をかぶった瓶（8面から）：届けた数で開く。隠れ色（「？」）。色の記号つき（色覚配慮）。動物は6種をプログラムで描画（logic.js 31行、render.js 22行）。
- 広告・課金・時間制限・毎日ボーナスなし。無料で1手もどす・やりなおし無制限。オフライン可。ひらがな中心。詰み・詰み予備軍を知らせる（§1.1）。
- 無いもの（grep で確認）：毎日の挑戦、共有（share）、着せ替え、ヒント。動物は6種のみ。

## 3. 勝てる点・負けている点

勝てる点
1. 広告・課金・通貨がない。不満の1位に当たらない（出典は上）。ただし表向きに「広告なし」をうたう競合の方が不信を買っている例もあり、守り続けることが信用になる。
2. 「注文に応える」遊びの筋がある。競合の多くは「ただそろえる」だけ（表の「特になし」）。
3. 布と隠れ色で、面の途中に考える点が増える。IB-29（易しい）への手当てになる。
4. 色覚への配慮（記号）、ひらがな、44px、キーボード操作、動きを減らす設定。競合の検索要約には出てこない。
5. 無料の1手もどすが回数無制限。「詰む」不満の受け皿になる。
6. インストール不要で、オフラインでも動く。

負けている点
1. 面の数と変化が少ない。Water Sort Quest・Liquid Logic は毎日の挑戦、着せ替え、物語を持つ。いろびんは「毎日戻る理由」が無い（広告なし方針では、時間で急かす仕掛けも使わない）。
2. 見つけてもらえない。ストア・検索・ポータルに載っていない。競合は数十万評価がある。最大の差。
3. 絵と手触りの総量。大手は3D・背景・演出が豊富（確認できた範囲では）。
4. ヒント機能がない（Poki 版にはある）。ただし1手もどすが代わりになる。
5. 動物が6種のみで、IB-08（同じ動物が並ぶ）が残る。
6. 共有の導線がない。人に勧めるには自分で URL を送るしかない。

## 4. 「選ばれる理由」になりうる軸（3つ、おすすめは1つ）

### A（おすすめ）「広告なしで、注文に応える物語のある色水ソート」
- 刺さる人：広告に疲れたが色水ソートは好きな人。30〜50代の、スキマ時間に10分遊ぶ人（ペルソナC）と、子どもに安心して渡す母（ペルソナA）。動物の絵はどちらにも効く。
- 効き目：大。手間：小（今ある強みを見せる作業が中心）。
- 具体策（思い付きです）：
  1. 最初の画面と説明文の1行目で「広告ゼロ」と「動物に届ける」を言う（見つけてもらう文言づくり）。
  2. 面クリアのカードに共有ボタン（Web Share。1か所）。
  3. 動物を6種から増やし、IB-08 を直す。
- 直接的な原因：色水ソートの不満の中心は広告。根本的な原因：広告で稼ぐ作りだから、広告を抜くと別の差が要る。直近：広告なしを名乗り、注文の筋を前に出す。中長期：面の数と動物・布の変化を月1回足す。

### B「やさしくて詰まない、大人向けの癒やし」
- 刺さる人：高齢者（ペルソナB）、ゲームに慣れない人。ひらがな、無制限の1手もどす、記号、キーボードは既にある。
- 効き目：中。手間：中（IB-29「易しい」と逆方向になり、いまの方針とぶつかる）。

### C「毎日1問の挑戦」
- 刺さる人：毎日少しだけ遊ぶ習慣のある人（競合の毎日挑戦が示す需要）。
- 効き目：中。手間：中。ただし「毎日」はCLAUDE.md の中毒性の注意（時間で急かさない、ログインボーナスなし）に近く、ユーザー決定の範囲を確認する必要あり。

おすすめは A。理由：今の資産（広告なし、動物、布）がそのまま効き、手間が小さい。B・C は A の上に後から足せる。

## 5. どこで遊んでもらうのが向いていそうか（所見のみ）

以下は推測です：
- 自分のサイト（GitHub Pages）：維持費ゼロで広告なしを守れる。ただし集客は自分で作る。URL を貼れる場所（SNS・知人）頼みで、月1万回までの道は長い。
- アプリストア：色水ソートは大量にあり、見つかりにくい。広告なしを名乗る競合でも、実際のレビューでは「広告なしと違う」という不信が出ている（出典は上）。審査 4.3（似たアプリ）の注意と年$99の費用あり（docs/business/4-legal.md）。
- Web のゲーム集サイト：Poki には色水ソートの作品が既にある。見つけてもらえるが、広告を入れる前提で、広告なしとは両立しない。CrazyGames は試験公開を進めない（ユーザー決定）。
- 所見：月1万回の達成は「どこで」より「見つけてもらう入口」の問題。入口がある場所（ポータル）は広告前提、広告なしを守る場所（自分のサイト）は入口がない。この板挟みの整理が次の検討になる。決めるのはユーザー。

## 6. 注意（調べきれなかった点）
- ダウンロード数は4本中1本程度しか取れず、評価数が主な目安です。表の空欄は未取得で、ゼロではありません。
- レビューは検索の要約を通した傾向で、個別のアプリに紐づかないものが混ざります。

## PMへの要点（5行以内）
1. 色水ソートの不満の中心は「広告の量・長さ」と「単調さ」。いろびんは広告なしで前者を避けられ、動物の注文・布・隠れ色で後者に答えている。
2. 負けている点は、見つけてもらう入口がゼロなこと。毎日戻る理由と着せ替え・物語のある競合もある。
3. 差別化のおすすめは A「広告なしで注文に応える色水ソート」。刺さる人は広告に疲れた大人と、子どもに渡す親。手間は小・効き目は大。
4. 共有ボタン、動物の追加（IB-08 の解消）、説明文の1行目に「広告ゼロ・動物に届ける」が、効く順の小さな改善。
5. 遊ぶ場所は、広告なしを守る場所は入口が無く、入口のある場所は広告前提という板挟み。決めるのはユーザー。
