# 5. 集客（マーケティング）報告

追加条件（ユーザー原文）：「初期投資を小さくしたい」。有料広告は最後の手段。3か月計画は無料〜数千円（独自ドメイン程度）で組む。

## 0. 先に正直な注意
事実に基づいて：今回のWeb検索では、日本のサイト（unityroom、ふりーむ！）や「個人開発者がXで何人に届いた」の信頼できる数字は見つかりませんでした。実例は英語圏の自己申告が中心で、平均値ではありません。下の「実例」はすべて「当たった例・外れた例」の参考で、期待値として使わないでください。

## 1. 現状の確認（事実）
/home/user/game-no1/index.html を確認：title は「ゆびあそび」のみ。検索で見えたのは GAMES 配列と最近遊んだ順の処理で、OGP（SNSで貼ったときの画像・説明）やシェアボタン、アクセス計測の記述は見つかりませんでした（Grepで og: twitter: analytics share が該当なし。完全な確認ではないので担当者が再確認してください）。

## 2. 集客の道（お金のかからない順）
実例の出典つき。相性は「ゆびあそび＝広告なし・ログイン不要・即遊べる・ひらがな多め・12本」から見た推測です。

| 道 | 届く人数の目安 | 手間 | 相性（推測） |
|---|---|---|---|
| Reddit（r/WebGames 等）・itch.io | 当たれば数百〜数千プレイ、外れれば数十 | 小〜中 | 中。英語が必要。ブラウザで即遊べる点は強い |
| X・TikTok・Shorts の遊ぶ動画 | 運次第。数百〜数百万の幅 | 中（毎週撮影） | 高。キリトリ道場・ミチビキ空港は絵になる |
| ブログ・note（「AIで1週間に12本」） | 話題性は高いが人数は不明 | 中（記事1本数時間） | 高。作り方自体が物語。ゲームより届く可能性 |
| Show HN・Product Hunt | 当たれば当日数千、外れは数十。無名には不利との指摘 | 小 | 中。「AIで12本」が技術者に刺さる可能性 |
| ゲーム集サイト（Poki・CrazyGames） | 掲載できれば桁違い（Poki 2025年に累計6.25億プレイヤー、CrazyGames 月間5,000万人との自己申告） | 大（審査、SDK対応） | 低〜中。審査制で、広告表示が前提。「広告なし」方針と衝突。PWA・localStorage 前提も作り変えが要る |
| unityroom・ふりーむ！ | 今回は数字不明 | 中 | 低。unityroom は Unity 製が前提。ふりーむ！は条件を未確認 |
| 口コミ・シェアの仕掛け（結果画像） | 1人が数人に紹介する程度 | 中（実装） | 中〜高。ただし現状シェア機能なし |
| 保育・介護・学校へ直接紹介 | 1施設あたり十数〜数十人 | 大（営業） | 高い可能性。ひらがな多め・広告なし・ログイン不要が安心材料。ただし収入に変えるには別の話（他担当へ） |
| ASO（アプリストア） | ストアに出していないので現状は対象外 | - | 現状なし。ストア公開は費用と審査が要るので後回し |
| 有料広告 | お金に比例 | 小 | 最後の手段（ユーザー指示） |

### 実例（出典）
- itch.io の個人開発者：HTML5ゲーム「Survival Idle」はReddit等で共有し、24時間で1,000人超が遊んだ。https://itch.io/devlog/1108868/survival-idle-from-prototype-to-1000-players-in-24-hours.amp
- 外れ例：同じく HTML5 の「PathJack」は2週間で itch.io のページ閲覧29。対面の宣伝のほうが効いた。https://itch.io/devlog/1009808/progress-report-1-the-good-fight.amp
- r/gamedev の書き込み（逸話）：ブラウザ版はダウンロード版の約20倍遊ばれる、r/WebGames に出すと数百〜数千プレイになり得る。https://itch.io/post/11304564
- TikTok：YAPYAP の最初の投稿が150万回再生、拡散の大半は紹介系クリエイターの動画。https://presskit.gg/field-guides/tiktok-indie-game-marketing （ブログ記事で一次データ未確認）
- Poki/CrazyGames の規模：https://app.cinevva.com/guides/publish-game-poki 、https://tr.linkedin.com/in/yagizefemertol （自己申告・第三者ガイド。1本あたりの収益は不明）
- Show HN・Product Hunt：2025年の「ゲームの」実例は見つからず。ガイドは「無名の個人には Product Hunt は不利」と述べる。https://hub.causo.ai/guides/show-hn-launch-playbook-technical-founders-2026

以下は推測です：個人の作品への反応は「0に近い」が最頻で、時々当たる分布です。1つの道に賭けず、安い道を複数回試すのが合理的です。

## 3. 今の製品に足りない集客の部品（優先順）
1. アクセス計測：Cloudflare Web Analytics か GoatCounter（どちらも無料・クッキーなしをうたう。https://www.cloudflare.com/en-in/web-analytics/ 、https://goatcounter.com/ ）。注意：CLAUDE.md の外部送信の決まりとの整合を、ユーザーに確認してから入れる。送るのはページ閲覧のみで、遊びの内容は送らない設計にする。ふだんはデバッグ以外「何もしない」方針の common/ に足すなら sw.js の APP_FILES とオフライン時の失敗処理が必要。
2. OGP画像・説明文（無料）：Xで貼ったとき見栄えが決まる。最優先で安い。
3. 紹介ページ・スクリーンショット・15秒動画（無料）：動画は端末の画面収録で撮れる。
4. シェアボタン（結果を画像・文章で共有、無料）：iPhoneの共有シートを使えば外部送信なし。
5. 独自ドメイン（年1,500〜3,000円程度と推測、価格は未確認）：github.io のままだと、サイトを移したときリンクが死ぬ。早めに取る価値あり。
6. 英語版（無料〜小）：Reddit/itch.io/HN を使うなら必須。ただしひらがな多めの魅力は薄まる。最初は1〜2本の英語紹介で足りる。
7. 保育・介護向けの1枚紹介（PDF/QR、無料）。

## 4. おすすめ：最初の3か月の計画（週10時間、無料〜ドメイン代）
方針：まず「測れる状態」を作り、その後は「物語を書く」と「動画を出す」を毎週回し、反応のあった道だけ増やす。

- 1〜2週（計20h）：独自ドメイン取得、OGP画像、紹介ページ、計測（承認後）、スクショ・動画素材。
- 3〜4週（20h）：note/ブログで「AIで1週間に12本」記事を公開。X、Reddit(r/WebGames)、itch.io(ブラウザ版へのリンクページ)に投稿。1本は英語。
- 5〜8週（40h）：週2本、ゲーム別の15秒動画をX・TikTok・Shortsに同時投稿（1動画＝1ゲーム）。シェアボタン実装。結果を見て良かった道を決める。
- 9〜10週（20h）：Show HN 1回。保育・介護の近い知り合い3〜5か所に直接紹介し、感想を聞く。
- 11〜13週（30h）：反応の良かった道を倍にする。やめる道を決める。有料広告はやらない。この時点の数字を見て、広告・課金・ストアの判断（別担当の領域）へ。

計：約130時間。費用：ドメイン代（数千円以内）のみ。

### 最初に測る数字（KPI 3つ）
1. 週のユニーク訪問者数（計測が入るまでは動画再生数などで代用）
2. 翌週も戻ってきた人の割合（ホーム画面追加・再訪の指標。ゆびあそびの本当の価値はここ）
3. 1人あたり遊んだゲーム数（12本のうち何本触られたか。ゲーム集としての魅力を測る）

## 5. 推測と注意
- 以下は推測です：週10時間・無料中心で3か月の到達は、数百〜数千人の再訪者が現実的で、「本業並みの収入」に直結する規模ではありません。集客は収益化の手前の「検証」と位置づけるべきです。
- ここからは思い付きです：「AIで1週間に12本作った」という作り方の物語が、ゲーム本体より先に広まる可能性があります。ゲームは「実物の証拠」として使う。
- 日本のサイト（unityroom、ふりーむ！）の最新の掲載条件・実績は未確認。必要なら続けて調べます。

## PMへの要点

1. 事実：日本のサイト（unityroom、ふりーむ！）や個人開発者の到達人数の信頼できる数字は見つからず。実例は英語圏の自己申告のみ（当たり：Reddit 経由で24時間1,000人超／外れ：2週間で閲覧29）。個人作品は「ほぼ0〜時々当たる」分布と見るべき。
2. 3か月計画は無料＋独自ドメイン代（数千円）だけ。約130時間（週10時間）：準備→note「AIで1週間に12本」記事＋Reddit/X→週2本の15秒動画→Show HN→保育・介護の知り合い3〜5か所へ紹介。
3. 足りない部品の優先：OGP画像、紹介ページ・動画、シェアボタン（共有シートで外部送信なし）、アクセス計測（Cloudflare Web Analytics／GoatCounter。外部送信になるのでユーザー承認が先）、独自ドメイン。
4. Poki/CrazyGames は審査制で広告前提のため、今の「広告なし」方針と衝突。KPI は週のユニーク訪問者、翌週の再訪率、1人あたり遊んだゲーム数。
5. 推測：週10時間・無料での3か月は数百〜数千の再訪者が現実的で、本業並みの収入には届かない。集客は収益化の判断材料を作る検証期間と位置づける。
