## 3. チームの見落とし

以下は推測です（計算の根拠は書く）。

1. **「本業並み」の物差しがずれている。** まとめは「年500万円」、2-monetize.md は「売上で月40万円」、3-finance.md は「手取りで比べると副業の利益で年約700万円」。売上と利益と手取りが混ざっている。投資家としては 3 の700万円が正しい物差しで、ほかの案の「必要な人数」は約1.4倍に読み替える必要がある。
2. **二重計上と楽観。** 3-finance.md の「ふつう 年74万円」のうち60万円は受託で、もう消えた。残り14万円も「宣伝費0円で平均 DAU 300」が前提だが、今の DAU は測ってすらいない（計測なし）。**分母が観測ゼロの数字に「ふつう」と付けるのは楽観。**
3. **Poki と自分のサイトはぶつかる。** Poki の分配を選ぶと Web 独占（5〜7年）なので、そのゲームは github.io から外すことになる。「自分のサイトは広告なしで残す」と「Poki で稼ぐ」は、同じゲームでは両立しない。両立するのは CrazyGames。
4. **「Mac が必須」は事実が違う**（表の6）。後回しの結論は審査の理由で変わらない。
5. **作り手の強みの使い方が浅い。** 「1週間に12本」を受託の見本に使う案しかなかった。この速さの本当の価値は、**当たるかを安く何度も試せる**こと。CrazyGames の Basic Launch は、収益は0だが**無料で実際の客に遊ばせて数字（遊ばれた時間など）を返してくれる市場テスト**になる。一方で、速さは誰でも Claude を使えばまねできるので、それ自体は**守れる強み（堀）ではない**。売り物は「速さ」ではなく「当たった1本」にしかならない。
6. **ブロックパズルとばいばいタイルは売り物から外すのが前提。** 外すと12本が10本になり、残りのうち型をなぞったもの（いろびん・まとめてポン等）はポータルでも飽和したジャンル。勝負できる弾は実質4〜6本。
7. **時間の値段。** 週10時間＝年520時間で年700万円なら、時給約13,500円が必要（700万÷520）。本業より高い時給を、無名・集客ゼロで出す計画になっている。

## 4. 判定

**出資しない**（「本業並み」を1年目の目標とする限り）。

理由：受託を外すと楽観でも年約100万円で、物差し（約700万円）の約7分の1。届く道は「当たり作」だけで、その確率を示す数字が1つもない。

**目標の置き直し（これなら次の段階で出資を考える）**：
- 目標を「収入」ではなく「**当たりの証拠**」に置く。半年で「1本で月に1万回以上遊ばれる作品を1本作る」。
- 1年目の収入目標は**月5万円**（年60万円）。これは本業並みの約1割で、副業として本業の時間を削らずに届く上限に近い。
- この2つに届いたら、その1本を軸に App Store・Poki の独占契約・広告を、そのときの数字で決める（広告なしの方針は「結果を見てから」のとおり）。

## 5. 最初の3か月の案（1つに絞る）

ここからは思い付きです。

**CrazyGames の Basic Launch で「多産多死」の市場テストをする。**
- 対象はオリジナル寄り・権利が低い作品から6本（ゼンマイさんぽ、ピカッと早押し、ハシわたり、キリトリ道場、ミチビキ空港、ほしくだき など）。ブロックパズル・ばいばいタイルは出さない。
- 1か月目：英語の文言・外部への通信（Google Fonts など）を外した版を作り、SDK なしで Basic Launch に出す（費用0円）。自分のサイト（github.io）はそのまま広告なし。
- 2か月目：Basic Launch の数字（500回に届くか、遊ばれた時間）で上位2本を選び、SDK を組み込んで本格公開（ここで初めて、その2本のポータル版にだけ広告が入る）。
- 3か月目：上位2本を磨き、新作を2本足す。速さはここで使う（外れは捨て、当たりだけ磨く）。
- 本業への負担：決まった日時の拘束なし、顧客対応なし。週10時間の範囲。
- **やめる基準**：3か月で Basic Launch を通る作品が0本なら、ポータルの線は止め、A（記事）に切り替える。
- 先にやること：会社の就業規則で副業の可否と届け出を確かめる。会社の PC・アカウント・Claude の契約は使わない。CrazyGames の最新の規約（2025-08-18版）を自分で読む。

以下は推測です：お金も本業の時間も使わずに、一番足りない「どれが遊ばれるか」の数字が手に入る。3か月の収入は0〜数千円の見込みで、それでよい。
