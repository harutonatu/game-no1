# 3. 事業の収支（お金）— ゆびあそび

作成：収支担当（2026-10-23）。為替は **1ドル＝150円** で計算（以下は推測：直近の水準からの仮置き）。

---

## 0. 結論（先に）

- **おすすめは「Web のまま・初期投資ほぼ0円の道」**（独自ドメイン＋無料ホスティング＋広告、同時にゲーム集サイトへ出す）。初期費用は約2,000円、月々は今払っている AI 代だけ。
- ただし **1年目に本業並み（年500万円の手取り）には届きません**（ふつうの見込みで年10万円前後）。届くには「当たり1本（毎日数千人が遊ぶ）＋受託の仕事」の組み合わせが要り、**2〜3年**が現実的な目安です（以下は推測）。
- iPhone アプリ化は Mac か貸し Mac が要るので **【初期投資が大きい】**。Web で「遊ばれる」ことを確かめてからにします。

## 2. 手数料（取られる割合）

事実に基づいて：
- **App Store（日本）**：2025年12月18日の「スマホ新法」施行後、小規模事業者プログラム（年100万ドル以下）は **10%＋Apple の決済を使うと5%＝計15%**。一般は21%＋5%。https://gigazine.net/news/20251218-msca-apple-google 、https://www.itmedia.co.jp/news/article/2512/18/1251218081/
- **Google Play**：年100万ドルまで **15%**（申し込みが必要）。https://support.google.com/googleplay/android-developer/answer/112622 。日本の新法後の変更は公式で要確認。
- **Web 広告（AdSense）**：作り手の取り分は **約68%**。https://support.google.com/adsense/answer/180195

- **CrazyGames**：広告収入の約60%（2026年のゲームジャムの条件。通常掲載は未確認、€100から支払い）。https://app.cinevva.com/guides/publish-game-crazygames
- **Stripe（Web で直接売る場合）**：国内カード **3.6%**、初期・月額0円。https://saas.imitsu.jp/cate-payment/service/4390/price

## 3. 稼ぎ方ごとの1年目の見込み（楽観・ふつう・悲観）

以下は推測です。前提の数字：
- **ARPDAU**（1日に遊んだ人1人あたりの1日の広告収入）：ハイパーカジュアルのアプリで **0.01〜0.05ドル（1.5〜7.5円）**（https://www.juegostudio.com/blog/arpdau-benchmarks-by-game-genre ）。日本の全画面広告の単価（1,000回表示あたり）は約11〜15ドルと高め（2024年、https://gamedevreports.substack.com/p/tenjin-ad-monetization-in-mobile ）。Web のバナー広告はアプリより低いとみて、**Web 0.5〜3円、アプリ 1〜4円**と置きます。
- **DAU**（1日に遊ぶ人の数、1年の平均）：宣伝費0円の個人で、悲観30人・ふつう300人・楽観3,000人（楽観は「SNS で1本当たる」水準）。
- 継続率：広告なし時代の今の数字が無いので、上の DAU に織り込み済み（ふつう＝翌日に戻る人が2〜3割と想定）。
- 計算式：**広告売上 ＝ DAU × 365日 × ARPDAU**（取り分差し引き後の値として置く）。

| 稼ぎ方 | 悲観 | ふつう | 楽観 | 前提 |
|---|---|---|---|---|
| ① 買い切りアプリ（300円） | 50本×255円＝**1.3万円** | 300本＝**7.7万円** | 2,000本＝**51万円** | 手取り255円＝300×0.85。無名の有料アプリは売れにくい |
| ② Web 広告 | 30×365×0.5＝**0.5万円** | 300×365×1＝**11万円** | 3,000×365×3＝**329万円** | AdSense 68% 後の値 |
| ③ アプリ広告＋広告を消す買い切り（480円） | 広告1.8万＋消す0.4万＝**2.2万円** | 広告22万（300人×2円）＋消す8.2万（1万DL×2%×408円）＝**30万円** | 広告329万（3,000×3円）＋消す122万（10万DL×3%）＝**451万円** | 消す手取り408円＝480×0.85 |
| ④ ゲーム集サイト提供 | 採用されず **0円** | 20万回×1,000回あたり1ドル＝**3万円** | 500万回×3ドル＝**225万円** | 1,000回あたりの単価は公表なし（要の不確かさ）。英語化が前提 |
| ⑤ BtoB 受託（販促ミニゲーム等） | **0円** | 30万円×2件＝**60万円** | 50万円×6件＝**300万円** | 単価は推測。本業の就業規則（副業・競業）の確認が先 |

**1年目の利益**（売上 − 固定費）：最小の道（②＋④＋⑤）の固定費は年約1.4万円（ドメイン＋会計ソフト）。ふつうなら 11＋3＋60＝**約74万円の売上、約72万円の利益**。受託を除くと **約14万円**。iPhone アプリ（①③）は Mac 込みで初年度 約11〜14万円かかり、ふつうの見込みでは①は赤字、③はほぼトントン。

## 4. 損益分岐と「本業並み」の条件

**損益分岐**（計算）：最小の道の固定費 年1.4万円 ÷（365日×1円）＝ **DAU 約40人**で元が取れます。iPhone アプリ（初年度約14万円）なら DAU 約190人（2円で計算）。

**本業並み（手取り500万円）**：以下は推測です。会社員の手取り500万円は額面で約650〜700万円。副業の利益は本業の給料に上乗せで課税されるので、**副業の利益で年約700万円**が目安です。
- 広告だけなら：700万 ÷ 365 ÷ 3円 ＝ **DAU 約6,400人**（1円なら約19,000人）。これは個人の宣伝費0円では「当たり作」の水準で、**1年目には届かないと見るのが正直な見立て**です。
- 現実的な道（組み合わせ・期間）：
  1. 1年目：Web＋広告＋ゲーム集サイトで「どのゲームが遊ばれるか」を測る。同時にサイトを作品集にして受託を1〜2件（目標 売上70万円）。
  2. 2年目：遊ばれた1〜2本だけを英語化・アプリ化（ここで初めて Mac を検討）。DAU 1,000〜2,000人＋受託4件（目標 300〜400万円）。
  3. 3年目：当たり作の DAU 5,000人前後＋受託で **700万円に届く可能性**（届かない確率の方が高い、と書いておきます）。

## 5. 作り手の時間と税金の基本

**時間**：以下は推測です。本業と並行で **週10時間**（平日1時間×5＋休日5時間）＝年約520時間。ふつうの見込み（受託なし 約14万円）なら **時給 約270円**。本業の時給（年収÷約2,000時間、例：年収700万なら3,500円）より大幅に低く、最初の1年は「お金」より「確かめる期間」と割り切るのがよいです。受託は時給が見えやすい（30万円÷60時間＝5,000円）。

**税金**（事実に基づいて）：
- **20万円ルール**：副業の「所得」（売上−経費）が年20万円以下なら所得税の確定申告は不要。ただし **住民税の申告は別に必要**。https://atsoho.com/blog/fukugyo-kakuteishinkoku-20man
- **開業届**：税務署へ出す紙1枚、0円。出すと「事業」として扱われやすくなります。
- **青色申告**：申請すると最大 **65万円** を所得から引けます（複式簿記の帳簿＋e-Tax 提出が条件）。ただし「雑所得」と判断されると使えません。継続して独立して行う事業であることが必要。https://www.freee.co.jp/personal-business/guide/articles/7012/
- C# の例えで言うと、帳簿は「ログ」、確定申告は「年1回のバッチで国に報告」、会計ソフトはそのログを正しい形式で書き出す道具です。
- 注意：会社の **就業規則で副業が許されているか** を最初に確認（特に受託は本業と近い）。

## 6. 初期投資が最小の道（まとめ）

ここからは思い付きです（費用は上の出典に基づく）。

- **中身**：①ホスティングを GitHub Pages から **Cloudflare Pages（0円・商用可）** へ移し、独自ドメイン（約2,000円/年）を付ける → ②何本かに控えめな広告（AdSense、承認が必要）→ ③英語版を作って **Poki・CrazyGames に応募**（0円）→ ④サイトを作品集にして **受託の窓口** を作る。
- **初期費用：約2,000円**（会計ソフトは売上が出てから年1.2万円）。Mac もストア登録も不要。
- **本業並みに届くか**：**1年目は届きません**（ふつう 約74万円、うち受託60万円）。届くのは、この道で当たり作を見つけて DAU 数千人＋受託を続けた **2〜3年後の可能性**としてです。それでも「小さく始めて、数字を見てから次にお金を使う」点で、失うお金が最も少ない道です。

## PMへの要点（5行以内）
1. おすすめは初期費用 約2,000円の「Web＋広告＋ゲーム集サイト＋受託」。iPhone アプリは Mac 込みで約11〜14万円の【初期投資が大きい】ので後回し。
2. GitHub Pages は商用の事業サイト利用が規約上不可 → Cloudflare Pages（0円）へ移すのが前提。
3. 1年目の見込み（ふつう）は売上 約74万円（うち受託60万円）、広告だけなら約14万円。損益分岐は DAU 約40人。
4. 本業並み（副業利益 約700万円）は広告で DAU 約6,400人が必要で、1年目は届かない。現実的には当たり作＋受託で2〜3年。
5. 税金は「所得20万円以下なら所得税申告不要（住民税は要）」、開業届＋青色申告で最大65万円控除。まず就業規則で副業可否を確認。
