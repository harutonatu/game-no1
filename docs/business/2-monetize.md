## 2. 月40万円に届くには（計算）

以下は推測です（上の数字からの計算）。
- (a) 480円の買い切り：手取り約408円（15%引き）→ **月約980本**。無名の個人には重い。
- (b) リワード広告：控えめに1,000回あたり10ドル≒1,500円 → **月約27万回**＝毎日約9,000回。1人1日2回見ても**毎日4,500人**が必要。
- (f) 月500円の支援：手取り450円 → **約890人**。身近な人向けでは届かない。
- (g) BtoB受託：1件15〜30万円と仮定 → **月2件前後**。
- (h) 2,000円の記事・テンプレート：手数料2割と仮定し手取り1,600円 → **月250部**。

## 3. 採点表（5段階、5がよい）

## 4. おすすめ

**今の方針のまま稼ぐ道 → (g) BtoB の名入れ版・受託。**
施設名・店名・キャラクターを入れたゲームを、保育園・介護施設・お店・地域のイベント向けに作る。ひらがな多め・44pxボタン・色覚配慮・オフラインで動く、という今の作りがそのまま売りになります。初期投資は名刺や独自ドメイン程度（数千円）。

**方針を緩める道 → (d) CrazyGames への提供（広告はサイト側が出す）。**
独占不要・無料で、自分のサイトは広告なしのまま。Poki は分配が手厚い代わりに「Webは Poki だけ」になるので、まずは CrazyGames で人気の出る作品を見極めてから考えます。

**総合のおすすめ → (g) BtoB の名入れ版。**
理由：本業並みに最も近く（月2件前後で届く計算）、初期投資がほぼ0円、方針とぶつからない。C#・Azureの業務開発の経験は「納期・見積・やり取り」で強みになります（例えるなら、パッケージ製品ではなく受託開発の案件）。

## 5. 作り手の強み「1週間で12本」の生かし方

ここからは思い付きです。
- **BtoB**：「見本を先に作って持っていく」営業ができる。相手の名前入りの試作を2〜3日で見せられるのは、普通の制作会社にない速さ。
- **(d)**：同じ型を何本も出し、数字（遊ばれた時間）のよいものだけ磨く「多産多死」が向く。
- **(h)**：作る過程（12本・テスト360項目・レビューの仕組み）そのものが教材。BtoB の宣伝にもなる。

## 6. 最初の1か月の小さな実験（初期投資：数千円以内）

1. **1週目**：架空の施設（例「ひまわり保育園」）の名入れ版を2本作る（既存ゲームの文字と色を差し替えるだけ）。1枚の案内ページ（できること・納期・目安価格「1本10万円〜」）を作る。
2. **2〜3週目**：知り合いのつてで**5か所**（保育園・介護施設・お店など）に見せて意見を聞く。
3. **4週目**：数える。「欲しい」と言った数、出せる金額、無料なら使うか。**5か所中1か所が「お金を出してもよい」と言えば続ける**、0なら (h) に切り替える。

並行して（任意・0円）：CrazyGames に2本だけ出し、実際の遊ばれ方を測る。

## 7. 注意（以下は推測です）

- **会社の副業ルール**を先に確認（本業がある場合いちばん大事）。副業の所得が年20万円を超えると確定申告が要る。
- **既存作に似た作品を売るときの権利**：特に「ブロックパズル」（テトリス型）は権利者が厳しいことで知られます。売り物にするのは、オリジナル寄りの作品（ゼンマイさんぽ・ピカッと早押しなど）を優先するのが安全。
- 本物の施設や会社の名前・ロゴを、許可なく見本に使わない。
