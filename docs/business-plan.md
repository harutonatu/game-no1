## 2. 結論

- 投資家の判定は**「出資しない」**。受託を外すと、1年目は楽観でも約100万円、ふつうなら数万〜20万円で、本業並みには桁が1つ足りない。
- 理由：集客がゼロ。型をなぞったゲームが多く差別化が弱い。週10時間で年700万円なら時給約13,500円が必要。
- **目標の置き直し**（投資家の提案。**ユーザーが採用**、2026-10-23）：
  1. 半年で「月1万回遊ばれる作品」を1本つくる
  2. 1年目は月5万円
  - 届いたら、その数字を見て App Store・広告・Poki を決める。

## 3. 次の3か月の案（投資家の提案。**採らない**、2026-10-23）

ユーザー決定「試験交換の進めません。試験するものも何も決まっていません。」（「試験公開は進めません」の意）により、今は進めない。何を試すかが決まったときの参考として残す。

CrazyGames（海外の大手ゲーム集サイト）の **Basic Launch**（試験公開。費用0円・収益0円・SDK 不要・広告なし）で、たくさん出して当たりを探す。

| 月 | すること |
|---|---|
| 1か月目 | オリジナル寄りで権利の危険が低い作品を6本選び、英語の文言にして、外部への通信（字体の読み込みなど）を外した版で Basic Launch に出す。自分のサイトはそのまま広告なし |
| 2か月目 | 数字（500回遊ばれたか、遊ばれた時間）の上位2本にだけ SDK を入れて本格公開する。広告が出るのは、この2本の CrazyGames 版だけ |
| 3か月目 | 結果を見て、続けるか決める |

- **やめる基準**：3か月で Basic Launch を通る（500回）作品が0本なら、ゲーム集サイトの線はやめ、「AIでゲームを作る方法」を記事で売る案に切り替える。
- 本業への負担：日時の拘束もお客さんとのやりとりもないので、最小。
- 候補の作品：ゼンマイさんぽ、ピカッと早押し、ハシわたり、キリトリ道場、ミチビキ空港、ほしくだき。ただし、ほしくだきは作り直しの方向が決まったところ（AS-07）なので、出すなら作り直しの後。
- 本格公開（2か月目）で広告が入るので、そこへ進む前に「広告なしの方針」をユーザーが決め直す。

## 4. 確かめた事実（6-investor.md で公式の資料を確認）

| 項目 | 結果 |
|---|---|
| GitHub Pages | 主に稼ぐ目的のサイトには使えない。稼ぐ段階で置き場所を移す |
| CrazyGames | 独占は不要（ほかで公開してよい）。本格公開では SDK の広告がゲームの中に入る。分配率は非公開 |
| Poki | Web では Poki だけで公開する契約（5〜7年）。自分のサイトと両立しないので、今は使わない |
| App Store の手数料（日本・小規模事業者） | 15%（10%＋Apple の決済5%） |
| iPhone アプリに Mac は要るか | **要らない**。GitHub Actions（公開リポジトリなら macOS も無料）か Codemagic（月500分無料）で作れる。本当の関門は審査 4.2（Web を包んだだけのアプリは落ちやすい） |

## 5. 法務で守ること（4-legal.md。弁護士の意見ではない）

- **ブロックパズルは危険度「高」**（本家の公式ルールに近い：同じ色の7種、10×20、SRS、ホールド、点数 100/300/500/800）。売る・広告を付ける・ゲーム集サイトに出す、のどれにも使わない。
- **ばいばいタイルは「中」**。お金を絡めるなら、説明文から「2048」を外す。ほかの10本は「低」（ミチビキ空港は「低〜中」）。
- お金を絡める前に、会社の就業規則（副業の可否・届け出・在職中に作ったものの権利）を確かめる。会社の PC・アカウント・Claude の契約は使わない。
- 相談は、まず無料の窓口（INPIT 知財総合支援窓口、自社の人事）を使う。
- 広告を入れるなら、プライバシーポリシー、外部送信の公表、子ども向けの判定が要る。ゲーム内通貨は有料にしない（資金決済法）。

## 6. 採らなかった案

| 案 | 理由 |
|---|---|
| 受託（施設・お店向け） | ユーザー決定「受託の線はありません。本業の足枷になります」 |
| Poki | Web で Poki だけの契約になり、自分のサイトと両立しない |
| App Store の買い切り | 今は集客ゼロで売れる根拠がない。審査 4.2 の作り直しも要る。数字が出てから |
| 広告（自分のサイト） | 方針の変更・法務の手間・置き場所の移転が要る。1年目は年十数万円の見込み |
