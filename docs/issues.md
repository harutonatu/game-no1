5. **公開**は、ユーザーの承認を得てから `git push origin <ブランチ>:master`（fast-forward）。公開後、ユーザーが実機で確認（tests/README.md の実機確認リスト。ピカッと早押しは iPad の4本・5本指ジェスチャーの確認 PK-27 も）。
