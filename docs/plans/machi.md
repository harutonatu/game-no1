### 4.2 MachiRender（B が作り、C が使う）

```js
const r = MachiRender.create(canvas, { cssW, cssH, dpr });
r.setState(state)                 // 新しく始めた・読み込んだ：オフスクリーンを全部描き直す
r.frame(state, events, dt)        // 毎コマ（変わる物が無ければ何もせず false を返す）
r.resize(cssW, cssH, dpr)
r.camera() → { cx, cy, cell }     // 見ている真ん中（マスの座標）と 1 マスの css px
r.setCamera({ cx, cy, cell })     // cell は 5〜28 に切る
r.panBy(dxCss, dyCss); r.zoomBy(f, pxCss, pyCss); r.fit()   // fit＝地図全体
r.cellAt(pxCss, pyCss) → { x, y, i } | null
r.setPreview({ tool, cells, ok, cost, label }) | r.setPreview(null)
r.setView('normal' | 'poll' | 'jam' | 'live' | 'land')
r.flash(i); r.focus(i)            // 市民の声を押したとき：そこへ寄って 2 秒光らせる
r.thumb(terrain, canvas)          // 地形えらびの小さな絵
r.stats() → { drawMs, chunks, cars, trains }   // テスト・デバッグ用
```

- 「こんざつ」の ふきだし は events `jam` を見て B が描く。カメラは B が持つ（ロジックは知らない）。
- `prefers-reduced-motion` では飾り（車・電車・煙）を止める。

## 6. 数値合わせ（A が `simulate` で測って書く）

約束 §5 の数値は仮。A は次を種 1〜8 で測り、この表に書いてから約束の数値を直す。

| 測る物 | ねらい |
|---|---|
| `greedy` で まち（1,000）までの月 | 遊ぶ時間で 5〜8 分（ふつうの速さ） |
| `greedy` で し（10,000）までの月 | 40〜60 分 |
| `none`（何も置かない） | 人口 0 のまま |
| `factory`（こうばを住む所のそばに固める） | 人口が一度 10% 以上減る・ほし 2 以下 |
| `grid`（みどり・せんろ・混ぜて置く） | 同じ年で `factory` より人口が多く ほし 3 以上 |
| お金 | `greedy` で はじめの 2 年に置く物が足りなくなる時がある（つまる緊張）が、マイナスが 12 か月続かない |
| 交差点 | 同じ量で 交差点だらけ の方が まっすぐ より渋滞の段が高い |
| 重さ | Node で 64×78 を `greedy` 20 年、`step` 1 回の中央と最大 |

**測った結果（2026-11-26・ロジック担当 A。`simulate(seed, policy, months, { choice: (seed − 1) % 3 })`、種 1〜8。1 か月＝4 秒）**

| 測る物 | ねらい | 測った値 | 判定 |
|---|---|---|---|
| `greedy` で まち（1,000）までの月 | 5〜8 分 | 94〜182 か月（中央 102 か月＝**6.8 分**。種 6・8（やまあい・かわ）は 169〜182 か月＝11〜12 分） | ほぼ合う（地形で長くなる時がある） |
| `greedy` で し（10,000）までの月 | 40〜60 分 | 795〜949 か月（中央 875 か月＝**58 分**） | 合う（上のはし） |
| `none`（何も置かない） | 人口 0 のまま | 20 年 0（8 つとも） | 合う |
| `factory`（こうばを すむ のそばに固める） | 一度 10% 以上減る・ほし 2 以下 | 一番へった割合 5〜46%（8 つ中 7 つが 20% 以上）・ほし 2 の時がある 7/8・ほしの平均 2.6〜3.0・20 年で 496〜997 人 | ほぼ合う |
| `grid`（みどり・せんろ・めぐみ・こうばを遠くに） | 同じ年で `factory` より多く ほし 3 以上 | 20 年で 2,976〜3,198 人（factory の 3〜6 倍）・ほしの平均 4.0〜4.1・最低 3 | 合う |
| お金 | `greedy` の はじめの 2 年につまる・マイナスが 12 か月続かない | はじめの 2 年の いちばん少ないお金 162〜439（はじめ 2,000）・マイナスの月 0 | 合う（マイナスは起きない決まりにした。下の ⑤） |
| 交差点 | 交差点だらけ の方が まっすぐ より段が高い | アパート lvl 1 を 4 列：まっすぐ 段 1（合計 11）・交差点だらけ 段 2（合計 13）・せんろ を通すと 段 0 | 合う（CL7） |
| 重さ | Node で 64×78 を `greedy` 20 年、`step` 1 回の中央と最大 | 20 年（3,700 人）：中央 **0.03ms**・95% 0.47ms・最大（月の終わり）約 1ms（最初の 1 回だけ JIT で 5ms）。75 年（11,000 人）：中央 0.03ms・最大 1.1ms。はやく（4 tick）中央 0.11ms。loadSave 10〜20ms・保存 34KB | 合う（約束 §6.3 の 3ms に十分） |

**ねらいに合わせて直した数値**（約束 §5.19 に書き写した）：
1. はじめのお金 20,000 → **2,000**（20,000 では 10 年たってもつまらない）。
2. 税を 1/4（アパート 0.15・マンション 0.35・住宅地 0.25・高級住宅地 0.75・仕事 1 人 0.12・めぐみ 0.2）。お祝いのお金 まち 3,000・し 10,000。かんこうきゃく 人口 × 0.2。
3. **来る人の上限**を足した：1 か月に来る人＝(10 ＋ 人口 × 0.0006) × ほしの倍率（★1 0.35・★2 0.7・★3 1・★4 1.2・★5 1.4）× おまつり 1.5。3 か月ぶんまでためる。すむ が育つ・建て替えで人が増えるときに使う（これが無いと お金がある限り数か月で まち になる）。置き方の良さ（ほし）で育つ速さが変わる。
4. すみやすさの基本 50 → **55**（みち と 仕事 があれば育つ）。出かける量 0.1 → **0.3**（交差点で渋滞が起きるように）。釣り合い r ＝ (仕事＋10)÷(はたらく人＋10)（小さな町で振れすぎない）。
5. **維持費は払える分だけ**（払えない分は待つ）：お金は月の計算でマイナスにならない（0 で育つ物も無く動けなくなる行き止まりを作らない）。こわす もお金が要る（マイナスの間だけは こわせる）。
6. 自動プレイの置き方：`greedy`＝いりぐちから 5 マスおきの格子に みち を伸ばし、r を見て すむ・しごと（遠い所）・おみせ を置く。`factory`＝しごと を すむ のそばに多めに。`grid`＝greedy＋区画ごとに みどり 1 マス・海辺や森のそばは めぐみ・まち で せんろ 1 本・お金がたまったら税 ひくい。
