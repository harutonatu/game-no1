## 1. しくみ（部品 ＋ 組み立て表）

- **部品**（手描き）：動物・もの を 1 つずつ、小さな文字の地図で描く（例：ねこ 10×10、テレビ 9×8）。
- **組み立て表**：1 枚の絵＝「どの部品を、どこに、左右ぎゃくにするか、色を置きかえるか、どの順に重ねるか」の短い記録。
  ```js
  { id: "nekoterebi", name: "ねこが テレビを みる", season: "",
    parts: [ ["teburu", 11, 8], ["terebi", 13, 0], ["nekosuwari", 0, 2, 0, { O: "C" }] ] }
  // [部品の id, x, y, 左右ぎゃく(0/1。省略は 0), 色の置きかえ(省略可。例 {O:"C"}＝オレンジを ちゃいろ に)]
  // 先に書いた部品が奥、後に書いた部品が手前。大きさ（この例は 25×12）は表に書かず、部品の外わくから求める
  ```
- **id は英小文字だけ**（例 `nekoterebi`。ハイフン・数字・大文字は使わない）。約束 §2.6 決まり 6 と、保存の `pic`（§4.2）に入る id と同じ決まり。AL16 で確かめる。部品の id も同じ決まり（例 `nekosuwari`）。
- **組み立て**：ゲームが面を始めるときに、組み立て表から 1 枚の文字の地図を組み立てる（後に書いた部品が前に重なる。部品の `.` は**すけている**＝下の部品が見える）。左右ぎゃくは部品ごと、色の置きかえは左右ぎゃくのあとに行う。組み立てた地図は、手描きの 48 枚と同じ決まり（§2.6 の 1〜8）を満たす。満たさない表は**テストで落とす**（作る人が直す。ゲームの中で勝手に直さない）。
- 組み立ては決まった計算なので、同じ表から毎回同じ絵になる（途中からの再開・1手もどす・ずかんで同じ）。
- **公開したら変えない**：公開した部品と組み立て表は書き直さない（遊んでいる人の保存・ずかんの絵が変わるため）。部品を直したいときは**新しい id の部品**を足し、それを使う新しい組み立て表を足す。公開した組み立て結果は tests/ に固定し、ちがえば AL16 を不合格にする（§7）。
- **組み立てる時**：面を始めるときはその 1 枚だけ。ずかんは開いたときに、**見える所に要る絵だけ**組み立てて、id ごとに覚えておく（同じページの中では 2 回組み立てない。まだの絵のかげも形が要るので同じ）。起動時に全部は組み立てない。

## 5. 見た目をそろえる・何の絵か分かる

- **試作のチェック**（本格的に作る前に必ず）：部品 9 個（ねこ・くま〔それぞれ「すわる」と「ちいさい形」〕・テレビ・おちゃ・ボール・じてんしゃ・テーブル）と、くみあわせ 5 枚（ひとり 1・動物＋もの 2・ふたり 2）を作る。「ちいさい形」は試作から作る（ユーザー決定 2026-10-28）。
- 見る人：PM・ユーザーと、**子どもか高齢の家族 1 人**（ユーザー決定 2026-10-28）。
- 判定：**題名を隠して見せて、何をしている絵か当てられるか**。見るのは**SE 縦（320×568）の画面での実寸**（1 マス約 9px。見本の一枚絵を拡大して見ると、実際より分かりやすく見えるため）。
- 当てにくければ、部品を大きくする・人数を減らすなど、決まりを直してから進む。**ふたりの絵が当たらなければ、ふたりの数を減らし**、その分を 動物＋もの に回す。
- 色覚：動物どうしは色だけでなく形（耳・しっぽ。§3 の表）で分かるようにする。

## 7. テスト

- **AL16（新設）**：
  1. 部品：全部が決まり（最大 16×14・使う文字・id は英小文字だけで重ならない）を満たす。
  2. 組み立て表：id が英小文字だけ（`^[a-z]+$`。ハイフン禁止）で、手描き・ほかの絵と重ならない。名前が手描き 48 枚を含むほかの絵と重ならない。`season` が決まりの値。存在しない部品を指していない。左右ぎゃくは 0 か 1、色の置きかえは決まりの文字だけ。
  3. 全部のくみあわせを組み立てると、約束 §2.6 の決まり 1〜5（大きさ・色と角砂糖の数が段の範囲・各色 3 個以上・閉じた空きなし）を満たし、同じ色のかたまりが 3 マス以上、`createLevel` が予備を使わず解ける（1 面 50ms 以内）。
  4. **内側に閉じこめられた色**（目・模様など）のある絵が、各段（M・L・XL）に 1 枚以上ある（約束 §2.6）。
  5. **ほぼ同じ絵がない**：場面の部品を除いた部品の種類の組が同じ絵が 2 枚ない。場面の部品を除いて 1 種類だけで、その種類が手描き 48 枚の題材（ペンギン・ひよこ・すいか・おにぎり・ケーキ・バス・ふね など）と同じ絵がない。
  6. **公開した組み立て結果が変わっていない**：公開した版の、各くみあわせの組み立て結果（id ごとの短い値）を tests/ の中のファイルに固定し、今の組み立て結果とちがえば不合格（部品の直しで、遊んでいる人の絵が変わるのを防ぐ）。新しく足した絵は、その版の公開のときに固定に足す。

### 8.1 ご褒美の見せ方（約束 §3.5・§3.8 を直すときの案）

- 完成したとき（`celebrate` とクリアのカード）は、**絵の名前を大きく出す**（「ねこが テレビを みる」）。くみあわせの絵は名前を読むと楽しい絵なので、名前がご褒美になる（以下は私の推測）。
- ずかんの「M / 全部の数」は**控えめに**（小さな字で）出す。絵が 200 枚を超えると、分母の大きさで「先が長い」と感じさせやすいため。
- どちらも約束 §3.5（クリアのカードの本文・ずかんの上の「M / 48」）の書きかえになるので、約束を直すときに PM が決める。
