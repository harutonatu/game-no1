## 1. しくみ（部品 ＋ くみあわせの表）

- **部品**（手描き）：動物・もの を 1 つずつ、小さな文字の地図で描く（例：ねこ 10×10、テレビ 9×8）。
- **くみあわせの表**（レシピ）：1 枚の絵＝「どの部品を、どこに、左右どちら向きで、どの順に重ねるか」の短い記録。
  ```js
  { id: "neko-terebi", name: "ねこが テレビを みる", season: "",
    size: [26, 18],
    parts: [ ["terebi", 15, 4], ["neko-suwari", 2, 7], ["yuka", 0, 17] ] }   // [部品, x, y, 反転?]
  ```
- **組み立て**：ゲームが面を始めるときに、表から 1 枚の文字の地図を組み立てる（後に書いた部品が前に重なる。部品の `.` は透明）。組み立てた地図は、手描きの 48 枚と同じ決まり（§2.6 の 1〜8）を満たす。満たさない表は**テストで落とす**（作る人が直す。ゲームの中で勝手に直さない）。
- 組み立ては決まった計算なので、同じ表から毎回同じ絵になる（途中からの再開・1手もどす・ずかんで同じ）。

## 5. 見た目をそろえる・何の絵か分かる

- **試作のゲート**（本格的に作る前）：部品 6 個（ねこ・くま・テレビ・おちゃ・ボール・じてんしゃ）と、くみあわせ 5 枚を作り、見本の一枚絵を PM とユーザーが見る。判定：**題名を隠して見せて、何をしている絵か当てられるか**。当てにくければ、部品を大きくする・人数を減らすなど、決まりを直してから進む。
- 32×24 で 2〜3 匹＋ものは窮屈なので、「ふたり」は部品を小さめ（動物 9×9 前後）にした「ちいさい形」をもう 1 つ用意するかを、試作で決める。
- 色覚：動物どうしは色だけでなく形（耳・しっぽ）で分かるようにする。
