### 1.1 IB-08：2 つの枠に同じ動物が並ばない

**原因（事実）**：`games/irobin/logic.js:1111-1121` の `animalFor(level, orderIndex)` は `perm[(i + floor(i/6)) % 6]`。続く 2 人（i と i+1）は必ず違うが、片方の枠のお客さんが待っている間にもう片方が何人も入れ替わると、6 番違いの人と並ぶ。render（`games/irobin/render.js:712-722` の `animalKind`）は注文の番号だけを渡す。

**1 か所目：`games/irobin/logic.js:1111-1121`（`animalFor`）**
変える前：
```js
  // お客さんの動物。orderIndex＝その面の注文の何番目か（0 から）。続く2人は必ず違う動物
  function animalFor(level, orderIndex) {
    const rng = makeRng(seedFor(level) ^ 0xA5A5A5A5);
    const perm = shuffle(rng, ANIMAL_KEYS.slice());
    let i;
    try { i = Number(orderIndex); } catch (e) { i = 0; }
    i = Number.isFinite(i) && i >= 0 ? Math.floor(i) : 0;
    if (i > 1e9) i = i % 6000000;
    const k = ANIMAL_KEYS.length;
    return perm[(i + Math.floor(i / k)) % k];
  }
```
変えた後（形。名前は変えてよいが、2 引数のときの結果は 1 つも変えない）：
```js
  // お客さんの動物。orderIndex＝その面の注文の何番目か（0 から）。続く2人は必ず違う動物。
  // otherIndex（省略可）＝いっしょに見えている もう1人の注文の番号。先に来た方（番号が小さい方）はそのまま、
  // あとの方が同じ動物なら perm の次の動物にする（2 つの枠に同じ動物が並ばない。IB-08）
  function animalFor(level, orderIndex, otherIndex) {
    const rng = makeRng(seedFor(level) ^ 0xA5A5A5A5);
    const perm = shuffle(rng, ANIMAL_KEYS.slice());
    const k = ANIMAL_KEYS.length;
    const norm = (v) => { let i; try { i = Number(v); } catch (e) { i = 0; } i = Number.isFinite(i) && i >= 0 ? Math.floor(i) : 0; return i > 1e9 ? i % 6000000 : i; };
    const posOf = (i) => (i + Math.floor(i / k)) % k;
    const i = norm(orderIndex), p = posOf(i);
    if (otherIndex === undefined || otherIndex === null) return perm[p];
    const o = norm(otherIndex);
    if (o < i && posOf(o) === p) return perm[(p + 1) % k];
    return perm[p];
  }
```
- `o < i && posOf(o) === p` の 1 行は変異 MB35 の置換元にするので、1 行のまま書く。
- 3 番目の引数が壊れた値（`NaN`・`-1`・`"x"`・`{}`・`Symbol()`）でも例外を出さない（`norm` が 0 にする）。

**2 か所目：`games/irobin/render.js`（`animalKind`・`setCustomer` と、それを呼ぶ所）**
- `animalKind(lv, color)`（712 行）を `animalKind(lv, color, other)` に。`other` はいっしょに見えている もう 1 つの枠の色（いなければ `null`）。`orders.indexOf(other)` が 0 以上ならそれを `L.animalFor(lv, idx, otherIdx)` の 3 番目に渡す。logic が無いときの予備（720〜721 行）は今のまま（同じ動物が並んでもよい。logic が読めない時だけ）。
- `setCustomer(i, color, lv)`（751 行）を `setCustomer(i, color, lv, other)` に。`other` が `undefined` なら `custs[1 - i]` の今の色を使う。
- 呼ぶ所（どれも「同じ時点のもう 1 つの枠」を渡す）：
  - `update`（821 行）：`setCustomer(i, want, level, slots[1 - i] === undefined ? null : slots[1 - i])`
  - `arrive`（1276 行）：`setCustomer(a.slot, color, level, slotsView[1 - a.slot] === undefined ? null : slotsView[1 - a.slot])`
  - celebrate のあと（1361 行）：`setCustomer(i, shown.slots ? shown.slots[i] : null, level, shown.slots ? shown.slots[1 - i] : null)`
  - `depart`（1265 行）は `null`（お客さんなし）なので変えない。
- 決め方は「先に来た方はそのまま」なので、待っているお客さんの動物は途中で変わらない。開き直したとき、先に来た方がもう帰っていれば、あとの方は本来の動物で出る（並ばないので問題ない。契約に書く）。
