## 1. 決めたこと
- **どこで選ぶか**：面えらびの一覧で、**クリアしたことのある面**（ずかんにある面。1〜150）に「ちょうせん」で遊ぶ道を付ける。面を押した後の確かめのカードに［ふつうで あそぶ］［ちょうせん］の 2 つのボタン（44px 以上）。まだクリアしていない面・「つづき」は ふつう だけ。ふつうの進み方（ベスト・つぎの めんへ）は今のまま変えない。
- **ちょうせんの決まり**：わく（`SLOTS`）が **2 つ**。1手もどすは **3 回まで**（残りの回数をボタンに出す。使い切ったら押せない）。やりなおしは何度でも（やりなおすと もどすの回数も 3 に戻る）。盤（絵・箱の配り）はその面の ふつう と同じ作り方でよいが、**わく 2 つで解けることを面を作るときに確かめる**（`solveSearch` を わく 2 で。解けない配りなら作り直し、決めた回数で見つからなければ ふつう の配りから箱を減らすなど PM が決める前に止まって報告）。
- **金の花輪**：ちょうせんでクリアした面（絵）に**金の花輪**（v62 の花輪の色の表を金・きいろ・しろに差し替え。`wreathUri`）。面えらびとずかんで、ふつうの花輪より金を優先して出す。説明の行に「金の わ ＝ ちょうせん クリア」も足す。クリアのカードに「ちょうせん クリア！」。
- **保存**：新しいキー `amai.gold`（ちょうせんでクリアした絵の id の一覧。`amai.clean` と同じ形・壊れていても落ちない・古い id も消さない）。ちょうせん中の途中の保存は**しない**（閉じたら ふつう の続きに戻る。わかりやすさ優先）。ベスト・ずかんの回数・amai.clean は、ちょうせんのクリアでも ずかんの回数だけ増やす（ベストは ふつう と同じく上がる面なら上がる…ではなく、ちょうせんはクリア済みの面だけなので変わらない）。
- **共有**：ちょうせんクリアのときは文に「ちょうせん」を入れる。
- 全ゲーム共通の決まり（文字 12px・ボタン 44px など。CLAUDE.md 1 章・テスト V・L）は変えない（W-11）。
