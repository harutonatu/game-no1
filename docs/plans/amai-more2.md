### 4.1 組み込み
- `docs/plans/amai-redraw/build.js` を広げ（この計画書 §1 の表と `amai-more2/<id>.txt` を読む）、50 枚を `games/amai/pictures-d.js` に書き出した。`sw.js` の `APP_FILES`・`games/amai/index.html` の読み込み・logic.js の Node の読み込みにも足した。pictures-a〜c.js は頭の説明の 1 行だけ変わった（地図は同じ）。
- `PICTURE_ORDER` に 101〜150 面を XXL で足した。`BASE_PICTURES` 100→150（くり返しは 151 面から）。`LEVELS` の最後の行を 37–150 に。メニューの `AMAI_IDS` も 150 枚。ずかんの「M / 150」・共有の文「ずかん M/150」は `PICTURE_ORDER` の長さから出る。面えらびの一覧は `levelChoices`（`BASE_PICTURES`）から 1〜150 面（main.js の予備の値も 150 に）。
- 測る台本：`measure.js`（pictures-d.js を読む）・`summary.js`（`BASE` 150・「XXL 新2(101–150)」の行）・`run4.sh`（1〜162 面。`FROM=101` で 101〜162 面だけ）。
- 今まで遊んでいた人のデータ（101 面より先へ進んでいた人。前回 amai-more.md §6.1 と同じ形）：
  - ずかん・ベスト・もどしなしの印は消さない・変えない。
  - 途中の保存が 101 面より先のくり返しの面：絵は `PICTURE_ORDER` にあるので保存の pick のまま続く（反転のくり返しのまま）。押した手が合わなければ同じ面の最初から。
  - その次の面からは、その面の番号の新しい絵。飛ばした 101 面〜の絵は、151 面から「ずかんに 0 回の絵を反転せずに先に」で全部出る。テスト AL17 に足した。
