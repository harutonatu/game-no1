## 12. 実装で変えたこと（計画とちがう点。文書はこちらに合わせた）

2026-10-25、実装のあと。上の本文より、この節が優先。

- **共有の知らせ（`share-note`）**：`.btns` の最初の子で `position: absolute` の吹き出し（場所を取らない。3.2 の「高さを先に取る」をやめた）。空のときは `visibility: hidden`。押すと閉じる。コピー成功は 3 秒で消える（ボタンの文字「コピーしました」が戻るのと同時）。失敗の URL 表示は押すまで残る。失敗の文は「コピーできなかったよ。ながおしで コピーしてね」。
- **横向き（背が低いとき）のボタン**：縦積みをやめ、1 行目「つぎの めんへ」「メニューへ」、2 行目「ともだちに おしえる」を幅いっぱい。BW23 は基準のまま。
- **`doShare` の `sharing`**：`showClearCard` でも false に戻す。
- **ヒント**：1 面の「1ぽんに 4つ」は U+2060 で折れない。布のヒントは 5 面（`CLOTH_INTRO_LEVEL`）だけ長い文、ほかの面は「おきゃくさんに とどけると ぬのが とれるよ」。
- **BL23 (d) の `hiddenAll`**：「前の面も隠れで、そこから 200 面まで全部が隠れになる最初の面」（答えは 40 面）。
- **NEWS の `[CLOTH_INTRO_LEVEL, "cloth"]`** は 5 面より前に節目が無いので実際には出ない（契約 §21.2 に 1 行）。
- **小さい画面**（`max-height: 700px` 以下）では届けた動物の列を隠す（計画どおり）。
