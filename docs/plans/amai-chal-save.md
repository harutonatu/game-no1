## 1. 決めたこと（C1〜C8）

| 番号 | 決め |
|---|---|
| C1 キー | 新しいキー `amai.chal`。形は `amai.save` と同じ（`v`・`level`・`pic`・`mirror`・`rep`・`presses`・`t`・`picSig`）に `used`（もどした印＝`chalUsed`）を足す。`makeChal(level, pick, presses, t, used)`・`validateChal(raw)`（logic）。`amai.save` は ちょうせんでは書き換えない（今までどおり） |
| C2 検査 | `validateChal`：`validateSave` の検査 ＋ `used` が true／false ＋ 面が 3〜`BASE_PICTURES` ＋ `mirror`・`rep` が false。だめなら null（例外なし）。目印は `saveFits`（絵・決まりの版 `RULE_V` が変わると合わない） |
| C3 開き直したとき | `amai.chal` が先。検査が通り・絵が `PICTURE_ORDER` にあり・`saveFits` が true・`canChallenge(level)`（今も ちょうせんできる面）・押した手を ちょうせんの面で `replay` できる → ちょうせんのその局面から（`chalUsed` も戻す）。どれかがだめ → 落ちずに `amai.chal` を消して ふつうの続き（`amai.save`）。`startLevel(…, { challenge: true, resume: true, used })` は再生できないとき false を返し何も始めない |
| C4 書く時 | `save()` の時（始めた・押した・もどした・やりなおした・動いている間 10 はこびごと・裏へ回る・閉じる）。`chal` なら `amai.chal` だけを書く。`custom`（setState）は書かない |
| C5 消す時 | ちょうせんでクリアした（`onWon` の ちょうせんの道。`amai.gold`・ずかんと同じ時）・ふつうの面を始めた（`startLevel` が ふつう＝面えらびの［ふつうで あそぶ］・まだの面・つづき・［つぎの めんへ］・`setLevel(n)`） |
| C6 消さない時 | やりなおし（押した数 0・印なしで書き直す）・1手もどす・だいじょうぶな ところまで もどす・ちょうせんの別の面を始めた（その面で書き直す）・上の「← メニュー」（リンクで離れる＝閉じたのと同じ。ふつうの途中の保存と同じ扱い）。PM の例の「メニューへ戻る」は、ちょうせんのクリアのカードの［メニューへ］ならクリアの時点で消えている。途中で「← メニュー」から離れた人が戻ってきて続きから遊べる方が、ユーザーの言葉（セッションが切れると続きから始まらない）に合うと判断した |
| C7 もどした印 | `used` を保存し、開き直しても金の花輪を付けない。印の無い ちょうせんは、続きからクリアしても金の花輪が付く（印で分かるため。ふつうの「途中から再開した面は 1手もどし なし の花輪なし」とはちがう） |
| C8 X-20 | 見張るキーを `[amai.save, amai.chal]` に。消すのも `removeKey`（stale の間は消さない・消したら覚え直す） |
| 文言 | 選ぶカードの説明から「とちゅうの ほぞんは ないよ」を外した。ちょうせんの途中で面を押したときは「いまの ちょうせんの とちゅうは きえるよ」 |

- 「ちょうせんをやめたら ふつうの続きへ戻る」：今の画面には「ちょうせんをやめる」だけのボタンは無い。ふつうへ移る道（面えらびの［ふつうで あそぶ］など）は選んだ面を始めるので、`amai.save` も選んだ面になる（今までと同じ）。`amai.chal` が壊れている・合わないときは `amai.save` の ふつうの続きから。「ちょうせんをやめて ふつうの続きへ戻る」ボタンを足すかは PM の判断（以下は私の思い付きです：面えらびの一覧の上に「ふつうの つづき N めん」を出す）。
