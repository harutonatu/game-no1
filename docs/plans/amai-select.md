# あまいものあつめ：面えらびと、もどしなしクリアの花輪

- 作成：2026-11-03（PM・Opus）。状態：**作る段**。
- ユーザーの言葉（そのまま。「麺」は音声入力の「面」）：「甘いもの集め、とてもいいです。改善要望です。麺のセレクト機能と、それから一手戻すを使わずにクリアしたときは、そのクリアした麺に花輪か何かをつけてください。」
- 質問の答え（そのまま）：選べる面「クリアした面と、その次の面 (Recommended)」（説明：遊んだことのある面をもう一度遊べる。まだの面は鍵つきで、絵は「？」のまま）。花輪「面えらびとずかんの両方 (Recommended)」（説明：これまでにもどしなしでクリアした記録にもさかのぼって付く）。

## 1. 決めたこと
- **面えらび**：画面の道具の列（`#tools`）か、ずかんの近くに「めん」ボタン（44px 以上）。開くと面の一覧（番号と小さな絵）。選べるのは **1〜ベスト＋1 面**。それより先は鍵つき（押せない・絵は影か「？」）。
  - ベストが 100 を超える人（くり返しの面）の扱いは担当が約束に合わせて決める（例：1〜100 面の一覧＋「つづき（ベスト＋1 面）」）。一覧が長くなりすぎない形に。
  - 選んだ面は**最初から**始める。いまの面を途中まで押していたら（押した数 1 以上）、確かめの一言を出す（「いまの めんの とちゅうは きえるよ」など。やりなおしの確かめと同じ形）。
  - ベスト（`amai.best`）は下げない。前の面をクリアしても、ベストより先でなければ変わらない。クリアのカードの「つぎの めんへ」は選んだ面の次へ。ずかん・花輪の記録は今までどおり付く。
- **花輪**：1手もどしを使わずにクリアした面（今の `amai.clean` の記録。さかのぼって付く）に、**面えらびの一覧とずかんの両方**で小さな花輪の印を付ける。ずかんの今の「★」（`main.js:740`）を花輪に置き換えるかは担当が見て決める（意味が同じなら置き換える）。クリアのカードの「1手もどし なし！」は残す。
  - 花輪は絵文字ではなく、ゲームの絵に合う小さな描画（CSS か canvas のドット）。色だけに頼らない形（輪の形）。
- 保存の形（約束 §4）は、増やさずに済むなら増やさない。増やすなら壊れた値でも落ちないこと。
