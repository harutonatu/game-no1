# あまいものあつめ：花輪を花輪らしく（花を大きく）

- 作成：2026-11-04（PM・Opus）。状態：**見本を作る段**。
- ユーザーの言葉（そのまま）：「花輪に見えないね　もっとお花を大きくして」（v61 の花輪＝緑の輪に桃色の点。games/amai/index.html の `.wreath`）

## 1. 決めたこと
- 花輪をドット絵の小さな絵（インラインの SVG。`shape-rendering: crispEdges`）にする。輪の上に **はっきり花と分かる大きな花**（5 枚の花びら＋黄色の中心）を 5〜6 個並べ、すき間に緑の葉。
- 大きさ：面えらび・ずかんの右上は **34px 前後**（今 26px）。説明の行の小さな花輪は 26px 前後。絵（ずかんの小さな絵・面の絵）の大事な所を隠しすぎないこと（右上のすみ）。
- 色だけに頼らない（輪の形と花の形）。花の色は ピンク・きいろ・しろ など 2〜3 色。ゲームの絵の色（約束 §5.2 の 10 色）に合わせる。
- まず **見本を 2 つ**作り、実際の画面（390×844 の面えらび・ずかん）で撮ってユーザーに見せる。決まった方で入れる。
