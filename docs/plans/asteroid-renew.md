## 1. 遊びの形（PM が決めた細部。数値は仮。自動プレイで測って直す）

### 1.1 世界と小惑星
- 世界の単位：1 マス `CELL = 8`。マス (c, r) の中心は `((c+0.5)·CELL, (r+0.5)·CELL)`。格子の原点は (0,0)。
- 小惑星 `rock`：`w × h` マスの格子（`mats` は長さ w·h の配列。0=空・1=いわ・2=てつ・3=こおり・4=きん・**5=ひかり**）。形はでこぼこの丸（種から決まる。ふちは自然に階段になる）。
- 大きさ：星 1 で半径 約 36 マス（直径 72 マス＝576 単位。画面の幅 360 より大きい）。星ごとに少しずつ大きく、上限 半径 64 マス（格子 最大 132×132 = 17,424 マス）。10 の倍数の星はボス（約 1.25 倍・硬い）。
- **ひかり**（マス 5）：ふちから 4 マス以内に、4〜12 マスのかたまりで散らす（星の大きさで 6〜20 か所。削れて新しいふちが出ると、その近くの奥のマスが ひかり に変わる仕掛けは入れない。最初から奥にも少し入れておく）。**どれか 1 マスが壊れると、つながった ひかり が全部まとめて砕け**、かけら 3 倍（出来事 `glow`）。
- はなれたかたまり（本体とつながっていないマス）は今と同じくまとめて砕ける（`chunk`）。
- てつの大きなかたまり・こおり・きん・相性（0.5〜3 倍）は今の決まり（§3.2・§3.3）を使う。

### 1.2 自機（全部自動）
- `ship = { x, y, ang, dir }`：位置（世界の単位）、向き（ラジアン。進む向き）、まわる向き `dir`（+1 / −1）。
- 動き：小惑星の残っているマスの外側を、ふちから `STANDOFF = 5` マスほど離れて、ふちに沿って回る（速さ `SHIP_SPEED = 70` 単位/秒）。いちばん近いふちに寄りすぎ・離れすぎを直しながら進む。ときどき（10〜20 秒ごと、乱数）まわる向きを変える。残りが少ないときは、残っているマスのほうへ寄る（どこまでも見つからないことが無いように）。
- 武器はすべて自機から撃つ（砲台 `turrets` は廃止）。ねらいは武器ごと（今の §3.8 の考え：たま＝いちばん近いマス、ちらし＝近いマスへ扇、どかん＝マスの多い所、いなずま＝てつ、ビーム＝奥へ掘る、ほのお＝こおり）。撃てる向きの制限は無い。
- 弾が届く距離 `RANGE = 18` マス。それより遠いマスはねらわない。

### 1.3 時間切れ（ちきゅうまで あと）
- 星ごとに残り時間 `limit(n)` 秒。飛んでいる間だけ減る（2 択・カード・閉じている間は止まる）。0 になったら `phase: 'lost'`（出来事 `lost`）：カード「まにあわなかった！ つよくして もういちど」→ その星を最初の形からやり直す（かけら・Lv・武器はそのまま。残り時間も戻る）。
- `limit(n)` は「ふつうに強くしていく遊び方（greedy の自動プレイ）」でかかる時間 × `LIMIT_MUL`。星 1〜3 は 1.8 倍、そのあと少しずつ下げて星 10 以降 1.25 倍くらい（§1.5 で測って決める）。
- 星 1 の目安：greedy で 3〜5 分、limit は 6〜8 分。

### 1.4 進み方（今のまま）
- かけら・強くする・2 択・4 枠・ひかえと入れ替え（星と星の間）・しんか（Lv10/20/30）・星 30 でエンディング・そのあとも続く。
- 25%・50%・75% の区切りの言葉（`milestone`）は残す。

### 1.5 測る（ロジック担当）
- `simulate('greedy', opts)` で星 1〜40 の時間を測る。目標：星 1〜30 の 1 つの星が greedy で 3〜5 分。合計（エンディングまで）は 6〜10 時間（§3.10 の目安のまま）。limit の倍率を決め、表を計画書 §6 に書く。
- 「何も強くしない」で星 1 が時間切れになること、greedy で星 1〜3 が時間切れにならないことを KL で確かめる。

### 1.6 保存（ユーザー決定「最初から」）
- `asteroid.save` は **v:3**。v:1・v:2（と読めない値）は**読まずに消す**：初めて v3 の main が開いたとき、`asteroid.save`・`asteroid.save.bak`・`asteroid.best` を消す（1 回だけ。印 `asteroid.v3 = '1'`。メニューのベスト表示もこれで消える）。`asteroid.help` は消して遊び方をもう一度出す。
- 星の途中も保存する（`mid`：`mats` は 1 マス 1 文字の文字列＋連長圧縮でよい・`hp` は 9 段・`left`（残り時間）・`ship` は保存しない＝開くと決まった位置から）。壊れた値は §8.3 と同じく落ちない・消さない（壊れた v3 は bak から）。
- X-20（ほかのタブ・古いページから書き戻さない）は今の main.js の仕組み（§21.4）をそのまま使う。

## 2. 見た目（D。docs/img/asteroid-renew-D.png）

- 背景：濃い青（例 `#0a1630`→`#06102a` の縦のグラデーション）＋小さな星（動かない）。
- 小惑星：中は暗い塗り（背景より少し明るい青）に薄いマス目の線。ふち（マスと空の境目）は**白い光る線**（太さ 2px＋ぼかしの光）。
- マスの種類の見分け（色だけに頼らない）：てつ＝中に十字の細い線、こおり＝斜めの線、きん＝金色の点、ひかり＝**オレンジと黄の明るいマス**（ゆっくり明るさがゆれる）。
- 自機：白い線だけの、先の丸い三角＋小さな炎。弾：たま 白、ちらし 黄、どかん 橙の輪、いなずま 黄の枝分かれ線、ビーム 水色に近い白の帯、ほのお 赤橙。
- 粒：壊れたマスから小さな白い粒が自機へ吸い込まれる（かけら）。ひかり は金の粒を多めに。
- 画面（カメラ）：自機を画面の中心より少し右下に置き、**小惑星の中心がいつも画面の左の向き**になるように回す（回る速さに上限。急に回らない）。拡大は固定（1 マス＝8 CSS px。SE 縦 320 幅で約 40 マス見える）。
- UI（index.html）：枠・文字・かけら・残り時間の棒は金 `#f2c14e`、ボタンは金の線の枠。上：「かけら N」「ほし N」・残り時間の棒・小さな地球の絵・「ちきゅうまで あと m:ss」。下：武器の行（今の DOM のまま、色だけ D に）・「あたらしい ぶき」・入れ替え。左上「← メニュー」。
- 時間が 30 秒を切ったら棒と字をオレンジにし、地球の絵を少し大きく（急かす音は鳴らさない。中毒性 A の方針）。

## 3. 性能（iPhone SE 第 2 世代・CPU 4 倍遅くで 1 コマ 8ms 以内が目標）
- 小惑星はオフスクリーンの canvas（世界の 1 単位＝1px×端末の倍率。最大 1056×1056 を超えるなら区画に分ける）に描いておき、**変わったマスだけ**塗り直す。ふちの線も、変わったマスのまわりだけ描き直す。
- 毎コマは「回して・ずらして drawImage 1 回」＋弾・粒・自機。粒は最大 300、弾は `SHOTS_MAX`。
- ロジックのねらい探しは、ふちのマスの一覧（変わった所だけ更新）から探す。全マスを毎 step 回らない。

## 5. 部品どうしの約束

### 5.1 AsteroidLogic（A が作り、B・C・E が使う）
```js
state = {
  star, phase: 'fly'|'choose'|'lost'|'clear'|'end', t,
  left, limit,                   // 残り秒・その星の最初の残り秒（UI の棒は left/limit）
  kakera, kfrac, slots, bench, offer, swap,   // 今と同じ形
  rock: { w, h, mats, hp, total, left /* 残りマス */, value, gen /* マスが変わるたびに増える整数 */, dirty /* 変わったマスの添字の配列。B が読んだら [] にしてよい */ },
  ship: { x, y, ang, dir },
  shots: [{ w, x, y, vx, vy, ... }], burns, cd, tries, cleared, totals, seed, rng, ms, bestT, hold
}
```
- 定数：`CELL = 8`・`STANDOFF`・`SHIP_SPEED`・`RANGE`・`MATS`（5 = ひかり を足す）・`WEAPONS`（今の 6 つ）・`LIMIT_MUL` の表・`ENDING_STAR: 30`・`SAVE_VERSION: 3`・保存キー（今のまま＋`SAVE_KEY_V3: "asteroid.v3"`）。
- 関数：`newGame(seed)`・`starInfo(n) → { w, h, radius, boss, mix, limit }`・`step(state, dt) → { state, events }`・`dpsOf`・`upCostOf`・`upgrade`・`slotCostOf`・`unlock`・`choose`・`swapChoicesOf`・`reserveSwap`・`progressOf(state) → { broken, left, total, timeLeft, timeFrac }`・`formatKakera`・`formatTime(sec) → "m:ss"`・`makeSave`・`loadSave(raw)`（v3 以外は null）・`saveVersionOf`・`validateBest`・`simulate`・`retry(state)`（lost のカードの「もういちど」。星を最初の形から）。
- 廃止：`turretsOf`・`turrets`・`BARRIER_Y`・`TURRET_Y`・`bounce`・`START_BOTTOM`・`setNear` の類い（C・B は使わない）。
- events の kind：`fire`（w, x, y, ang）・`hit`・`break`・`chunk`（cells）・`glow`（cells）・`bolt`（path）・`boom`（x, y, r）・`beam`（x, y, ang, len, w）・`burn`・`evolve`・`clear`・`lost`・`ending`・`milestone`・`swap`・`boss`。
- `step` は phase `fly` のときだけ進む。`clear` は演出の秒（今と同じ）を数えて次の星へ。`lost` は止まったまま（C が `retry` を呼ぶ）。

### 5.2 AsteroidRender（B が作り、C が使う）
- `AsteroidRender.create(canvas, { cssW, cssH, dpr }) → r`、`r.frame(state, events, dt)`（毎コマ。events はそのコマで集めたもの）、`r.resize(cssW, cssH, dpr)`、`r.burst(kind, arg)`（`'up'`・`'evolve'`・`'swap'`・`'unlock'`。自機がひかる）、`r.reset()`（星が変わった・retry のあと。オフスクリーンを作り直す）、`r.stats() → { fps, cellPx, view: { x, y, rot } }`。
- 粒の行き先は `state.ship`。カメラの回転は B が持つ（ロジックは知らない）。
- 動きを減らす設定（`prefers-reduced-motion`）では、カメラの回転をゆっくりに・粒を減らす。

### 5.3 DOM・効果音・保存（C が作る）
- 今の DOM の id は残す（武器の行・2 択・入れ替え・遊び方・さいしょから）。足す：`#timeBar`（残り時間の棒）・`#timeText`（「ちきゅうまで あと m:ss」）・`#lostCard`・`[data-cmd="retry"]`。消す：はね返し・バリアに関わるもの。
- 効果音：今の名前＋`glow`（ひかりが砕ける）・`lost`（まにあわなかった）。`bounce` は使わない。
- 遊び方のカード：「じきは じぶんで とびまわって うつよ。みているだけで いいよ」「ほしを ぜんぶ こわすと クリア。ちきゅうに つくまでに まにあわないと、もういちど」「したの ボタンで ぶきを つよく しよう」。
- メニューの説明（index.html の GAMES）：「おおきな ほしの まわりを じきが とびまわって こわすよ。ちきゅうに つくまでに こわしきれ！」。メニューの絵（`art: "asteroid"`）は D の色の線画にする。
