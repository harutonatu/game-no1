- **くり返しは目安に届かない（PM の判断待ち。直していない）**：`REPEAT_K`（8–25〜30–70）・`PULL_ADD.repeat`（−2〜+10）では 101〜112 面のゆるいが 53〜66% から下がらない。`OVER.repeat` を 1.02〜1.5 にすると 40〜51% になるが、作る時間が 150〜220ms（今は 23ms）になり、AL11 の replay 50ms の考え方（iPhone SE で面の始めに止まらない）に合わない。なお 101〜136 面で測ると今の値で 47%（くり返しの最初の 12 面は M・L の絵なのでやさしい）。案：①そのまま（101〜136 面で見れば目安の中）②`REPEAT_K` 10–30（101〜112 面で 53%）③`OVER.repeat` 1.05・`ANY_RATE.repeat` 0（51%・作る時間 約 150ms）。
