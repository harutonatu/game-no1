## 1. 決めたこと（D1〜D9）

| 番号 | 決め |
|---|---|
| D1 調べ方の前提 | 「落ち着いてから押す」遊び方（約束 §2.3 の「必ず解ける」と同じ前提）で調べる。運んでいる途中に押す遊び方まで広げると局面が多すぎる。そのため「とけない」は「落ち着いてから押す遊び方では、もう全部は運べない」の意味（途中で押すと助かる局面がまれにあるかもしれない。以下は私の推測。カードには［このまま つづける］があるので困らない） |
| D2 調べる関数（logic） | `makeRescue(state, { limit })`：1 段目は生成の solveSearch と同じ刈り方で「箱の数＋15」局面まで、2 段目は押せる列を全部（同じ局面は 1 回）。`run(n)` で n 局面ずつ進められる。結果は `solved`（とける。押す列も返す）／`dead`（とけないと言い切れた）／`unknown`（上限。何も言わない）。時計は使わない（手間の数） |
| D3 予備軍（doomed） | 箱を押して落ち着いたとき（`afterStable` で、押した手が 1 つ以上・うごかせないでない・クリアでない・setState の局面でない）に、`makeRescue(state, { limit: DOOM_LIMIT＝150 })`。`dead` のときだけ予備軍。予備軍は「この先どう押しても とけない」なので、1手もどす・とける ところまで もどす・やりなおし・面を始める まで続く（調べ直さない）。カードは予備軍になった最初の 1 回だけ（`doomTold`）。出せないとき（ほかのカード・裏・局面が変わった）は、次に落ち着いたときに出す。1手もどす・もどす・やりなおし・開き直しのあとは調べない（次に押して落ち着いたときに調べる） |
| D4 戻し先 | `makeRewind(states, { base0Sure })`：押した手の直前の局面（新しい方 k＝n−1 から 1 まで）を、1 局面 `REWIND_LIMIT`＝60 で調べ、`solved` の いちばん新しい k。合計 `REWIND_BUDGET`＝1,500 局面で打ち切り、見つからなければ k＝0（面の最初。生成で解けると確かめた局面なので「とける」と言い切れる）。setState の局面の k＝0 は言い切れない（`sure:false`。いろびん R5・R6 と同じ） |
| D5 調べる重さ | Web Worker は使わない（局面を送る写し・事前キャッシュのファイルが増えるわりに、区切れば足りる）。main が `later(…, 0)` で区切って進める：1 回に 12ms か 40 局面まで（テストの時計を止めた画面でも進むよう、局面の数でも区切る）。1 局面の手間は最大でも 1 回の落ち着き（箱 1〜3 つが運び切る）なので、1 回の長い処理は CPU 6 倍遅くでも 100ms を超えない見込み（§6 で測る） |
| D6 履歴の局面 | main が押す直前の局面を `hist` に積む（1手もどすで 1 つ捨てる。やりなおし・面を始めるで空）。開き直して途中から続けた面は `hist` が無いので、使うときに `replayStates(level, pick, presses)` で 1 回作る。setState の局面は今の `customHist` を使う |
| D7 ちょうせん | とける ところまで もどす は ちょうせんでも出す（PM 決定 §8）。ちょうせんの「1手もどす あと N かい」は減らさない。使った面は金の花輪を付けない（§8） |
| D8 保存 | 形は変えない（`amai.save` は押した手と t のまま。もどしたら手を切りつめて書く）。予備軍・もどした印は保存しない（開き直したら分からない＝花輪は今までどおり「途中から再開した面は付けない」） |
| D9 テスト用 | `getState()` に `doomed`（予備軍と分かった）・`rescuing`（戻し先を探している）を足し、`overlay` に `"rescue"`（予備軍のカード）。新しい関数は足さない（カードのボタンを押して確かめる） |

## 2. 画面と文言

- **うごかせない**（今のカード）：見出し・本文は今のまま。ボタンの先頭に主ボタン［とける ところまで もどす］（`data-cmd="rewindYes"`、`primary`、横いっぱい）。その下に［1手もどす］［やりなおし］（半分ずつ。今の `primary` は外す）。1手もどすを使い切った ちょうせんは［とける ところまで もどす］［やりなおし］。押した数 0 なら出さない（作りの上では起きない）。ヒントは今のまま。
- **予備軍のカード**（`overlay = "rescue"`、うごかせないと同じ下の小さなカード）：見出し「もう ぜんぶは はこべないよ」、本文「とける ところまで もどす？」、［とける ところまで もどす］（`rewindYes`・primary）［このまま つづける］（`close`）。出て 400ms は押せない。Esc は［このまま つづける］と同じ。閉じたあとのヒント「この ままだと ぜんぶは はこべないよ」（`HINT_DOOMED`）。
- **探している間**：カードを先に消し、ヒント「とける ところを さがしてるよ」。箱・1手もどす・やりなおしを受けない（`rescuing`）。ありんこはそのまま働く。
- **戻したあと**：`state = 履歴[k]`・押した手を k まで切りつめ・保存・音 `undo`・ヒント「ここからなら ぜんぶ はこべるよ」（`HINT_REWOUND`。setState の最初で言い切れないときは出さない）。1手もどし なし の印は消える（`noUndo = false`）。ちょうせんでは もどした印 `chalUsed = true`。
- 負けの言葉は使わない。ひらがな。ボタンは 44px 以上・SE 縦で崩れない（AW で確かめる）。

## 8. 続けて頼まれたこと（約束 §0.11。PM から同じブランチで）

1. ［この めんを ちょうせん］（ふつうのクリアのカード）・［つぎも ちょうせん］（ちょうせんのクリアのカード。主ボタン）。並びは 3 段のまま：主／［ずかん］［メニューへ］／［この めんを ちょうせん］か［つぎの めんへ］と［ともだちに おくる］（半分ずつ・14px・2 行まで）。［つぎも ちょうせん］の面は いまの面＋1〜200 → 1〜いまの面 の順で、金の無い・ちょうせんできる面の最初（いまの面は、もどして金が付かなかったときだけ最後の候補）。
2. もどしと花輪：ちょうせんで 1手もどす・とける ところまで もどす を使うと `chalUsed`（金の花輪を付けない・`amai.gold` に書かない・ずかんの回数は増やす・カードに「もどしたので きんの わは つかないよ」）。ふつうで とける ところまで もどす を使うと `noUndo = false`（「1手もどし なし！」の花輪なし）。やりなおし・面を始めるで印は消える。
3. ちょうせんの 1手もどすの 3 回の制限をやめた（`CHAL_UNDO`・`chalUndo`・ボタンの「あと N かい」・使い切ったときの［やりなおし］だけのカードとヒントを外した）。はじめのヒント「ちょうせん！ わくは 2つ・もどすと きんの わは つかないよ」・面えらびの説明「ちょうせんは わくが 2つ。もどさずに クリアすると きんの わ。とちゅうの ほぞんは ないよ」・遊び方の 4 行目に「ちょうせんで もどすと きんの わは つかないよ。」。
4. テスト：AW34・AW35 を直し、AW41 を足した。変異 MA49〜MA51（のこり 3 回）を外し、MA76〜MA80 を足した。
