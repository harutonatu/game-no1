## 1. 飾りの中身（PM の決定）

**守ること（いちばん大事）**：カードの高さを v45 より増やさない（SE の Safari ではもうぎりぎり。IB-47）。字は 12px 以上、文字と背景のコントラストを保つ。色だけで伝えない（今の文はそのまま残す）。`prefers-reduced-motion: reduce` では動かさない。テンプレートに保存データを `${` で入れない（L6）。

1. **帳面らしい台紙**：`#card[data-kind="book"]` の背景を、今の `--panel` に うすい あたたかい色のグラデーションと、ノートの罫線のような ごく薄い横線（`repeating-linear-gradient`、不透明度 0.04〜0.06）を重ねる。縁は 2px の金色系（`#ffd84d` を 50% ほど）の二重線風（`box-shadow` の内側）で「特別な帳面」に見せる。
2. **見出しの飾り**：「なかよしちょう」の両わきに小さな飾り（CSS の `::before`/`::after` に ✿ や ❀ などの文字。`aria-hidden` 相当で読み上げに出ないよう CSS の content にする）。見出しの上に、小さな旗の飾り（ガーランド）を CSS だけで描く（高さ 8px 以内。SE 縦・横の高さ 600px/500px 以下の画面では出さない）。
3. **動物ごとの札**：各行（`li`）を角の丸い札にする。背景はその動物の毛の色（render.js の `FUR`。main.js からは `R.FUR` が無ければ main.js に同じ 6 色の表を持つ）をうすく（不透明度 0.12〜0.18）、左の絵は丸いメダルの枠（直径は今の絵の大きさのまま、うすい明るい丸の背景と 2px の縁）に入れる。札の内側の余白は上下 2〜4px で、今の行の高さを超えない（SE の画面では余白 2px）。
4. **段のしるし**：名前と数の行に、小さなしるし 3 つ（もらった段は ★、まだは ☆。12px 以上・黄色。`aria-label` に「おしゃれ 2こ／3こ」のような文）を足す。文の「あと ○にんで ○○」はそのまま残す（色だけ・記号だけで伝えない）。行の高さは増やさない（名前・数と同じ行に入れる。入らない幅なら次の行の頭に回してよいが、SE 縦の高さが増えないことを写真で確かめる）。
5. **ぜんぶ そろった動物**：札の縁を金色にして、右上に小さな王冠（👑 ではなく CSS の文字 ♛ か、細い金色の三角 2 つ。どちらでも可）。「ぜんぶ そろったよ」の文は今のまま。
6. **開いたときの動き**：札が上から順に 40ms ずつずれて、ふわっと出る（opacity と 4px の上下だけ、1 枚 200ms）。`prefers-reduced-motion: reduce` では動かさない。300ms の押せない時間（v45）とは別で、押せる・押せないは変えない。
