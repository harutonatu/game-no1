# v47 計画：かぎの びんの開け方を分かるようにする

- ユーザーの報告（2026-10-27）：動画（101 面）と「真ん中の上段、青い色だけしか入らない瓶が変です」。質問「どこが変だと感じましたか？」への答え（そのまま）：「その瓶を開けなければならないのに、タッチすると開けることができない」。PM の提案を見たあとの答え：「進めて」。
- 事実：錠の仕組み（鍵の色を 1 本の瓶に 4 つそろえると開く）は正しく動いている。押すと錠が一瞬ふくらみ、下の一言が「かぎの びんは、○を 1ぽん そろえると あくよ」になるだけで、「あといくつか」が分からない。
- 作業の場所：`/home/user/wt-v45`、ブランチ `claude/v47-lock-hint`（v46 公開版 ab3cafe から）。
- ルールと保存は変えない。新しく足すのは表示のための数え方の関数 1 つ（logic.js）。その関数の分だけ変異テストを流す。

## 1. 中身（PM の決定）

1. **数え方**：`IrobinLogic.lockProgress(state, color)` を足す。鍵の瓶以外の各瓶について、上から続いている「見えている（hidden でない）その色」の数を数え、いちばん多い数（0〜4）を返す。封をした瓶（sealed）は 4。state や color がおかしいときは 0（落ちない）。
2. **錠の数**：錠の絵（`lockHtml`）のそばに、小さく「2/4」（いまの数／4）を出す。字は 12px 以上。SE 縦・横で隣の瓶や上のお店と重ならない。注ぐたびに更新する。読み上げ（瓶のボタンの aria-label）にも「★を 4つ かさねると あく。いま 2つ」を足す。
3. **押したときの吹き出し**：錠の瓶を押すと、その瓶の上（入らなければ下）に吹き出しを 2 秒ほど出す：「[★の記号] を 4つ かさねると あくよ（いま 2つ）」。記号は錠と同じ色と形（`markSvg`）。もう一度押す・ほかを押すと消える。動きを減らす設定ではふわっと出さず、そのまま出す。今の錠のふくらみはそのまま。
4. **言葉**：下の一言（main.js の `lockHint`・HINTS の lock・locked）と遊び方（main.js 888 行あたり）を「1ぽん そろえる」から「4つ かさねる」に変える。色は名前だけでなく記号も添える（青が 2 色あるため。例「こい あお（★）」。色の名前は render.js の色の表を見て、同じ名前・似た名前の色があるときだけでなく、いつも記号を添える）。
5. 遊ぶ画面の並び・高さは変えない。

## 2. テスト

- BL27（logic、smoke）：lockProgress の (a) 空の盤で 0、(b) 上に 2 つ続く瓶と 1 つの瓶で 2、(c) 下に隠れた同じ色は数えない、(d) 間に別の色が挟まると上の分だけ、(e) 封をした瓶で 4、(f) 鍵の瓶の中身は数えない、(g) 壊れた入力で 0。
- BW39（full）：101 面で、(a) 錠のそばに「N/4」が出て lockProgress と同じ、(b) ★ を注いで重ねると数が増える、(c) 錠の瓶を押すと吹き出しに「4つ かさねると あくよ（いま N つ）」と記号、2 秒ほどで消える、(d) 下の一言も同じ言葉、(e) SE 縦・横（ホーム画面・Safari）で吹き出しと「N/4」が画面の中・ほかの瓶と重ならない・12px 以上、(f) 動きを減らす設定でも出る。
- 変異：MB61（hidden を数える）、MB62（続いていなくても数える）、MB63（鍵の瓶の中身を数える）。
- 既にある BW（錠のふくらみ・BW33 の SE の配置など）と L6 がそのまま合格すること。
