## 1. 診断（事実）

「つまらない」の原因は絵ではなく**設計の骨**。契約書の 3 か所が重なって「失敗できないゲーム」になっていた。

1. **わくが 5 つ**あり 5 つ全部が同時に働く（§1.4・§1.5）→ 待っている箱がすぐ捌ける
2. **箱のありんこの合計＝角砂糖の数がちょうど同じ**（§1.6）→ 取り返せないむだが原理的に起きない
3. **1手もどすが何回でも使え、うごかせなくても負けにしない**（Q3・§1.9・§1.10）→ 失敗の代償がゼロ

実測の記録（§2.8）：**ゆるい遊び方でクリア 90〜100%、7 割でたらめでも 94% 以上**。
レビューの記録（docs/issues.md の AM-01〜AM-05）：中毒性 3（惜しい負け方）・5（難しさがちょうどいい）・品質 5（奥が深い）・6（選択に意味がある）が 3 点以下。**AM-01（後半に詰まる面を入れる）は v49 の時点で提案されていたが、Q-A「このまま やさしめ」と引き換えで見送った**。

見た目：「荒い」は 1 マスが約 8px（32×24 の絵を SE 縦の 248px の枠に入れている）。「空中を歩く」はありんこに**足場が無い**（絵の外や角砂糖の上を直線で歩く）。

## 4. 採らなかった案（理由つき）

- **砂糖がとける・箱が奥から押し寄せる**：「時間で急かす仕掛けは使わない」方針に反する。
- **砂糖が重力で崩れる**：面白くなる可能性は高いが、手間が大きく、絵を集めるご褒美（Q10 ずかん）と喧嘩する。
- **必ず解ける保証を外す**：解けない面は理不尽に感じられ、品質 4（公平）を下げる。★を手数で付ける部分だけなら後で足せる。
- **ドット絵をやめて図形で描く**：「荒い」の根本解決だが手間が大（絵 48 枚の描き直し）。R-4 で足りなければ次の段で検討する。
- **箱ごとに働きを変える**：品質 2（ルールが分かりやすい）を下げる恐れ。作り直しに近い。

## 6. ユーザー決定（2026-10-29）と、やめた案

### 決定（そのまま）
手詰まりになったときの扱いを 3 つの選択肢で尋ね、ユーザーの答えは **「1」＝「その面を最初からやり直す（絵も箱の配り方も同じ。何度でも挑める）」**。

### この決定の意味（大事な前提の確認）
ユーザーの言葉（そのまま）：「甘いものは、最終的にゼロになることが必要なんですよ その時絵を形づくっている。砂糖とありんこは最後には必ず両方0になるんですけれど、そこは認識合ってますか」。
→ **合っている。** クリアは「角砂糖が残り 0」（`logic.js:502` の `won: left === 0`）で、箱の持ち玉の合計＝角砂糖の数（§1.6）なので、運び切った時点で砂糖もアリも必ず 0 になる。絵は角砂糖そのもので形づくられている。**これは設計どおりの正しい姿で、変えてはいけない。**

### やめた案（PM の誤り。撤回した）
- **箱の持ち玉を 5% 少なくする**：砂糖が残って終わる＝絵が完成しない。両方 0 の前提に反する。**撤回**。
- **待っている箱の持ち玉が減る（アリが余る）**：アリが足りなくなって砂糖が残る。同じ理由で**撤回**。
- 事実の訂正：今の仕組みでは、ふちに自分の色が無い箱は**ありんこを出さずに待つだけ**で、持ち玉は減らない（`logic.js:492` の `if (i < 0) continue;`）。「無駄打ち」は存在しない。PM は一度「無駄打ちで減る」と誤って説明したので、ここに訂正を残す。

### 残る道（両方 0 を保ったまま緊張を作る）
手詰まり（わくが全部ふさがり、どの箱もふちに自分の色が無い）を**救済せず、面のやり直しにする**。段 0 の測定では、わく 3 で手詰まりは 1 面に 1〜2 回起きていた（＝もどし 3 回で元に戻った理由）。

### ユーザーの指摘（そのまま）と、分かったこと

「ちょっと待って枠3つで、それでもタスククリアできるっていうのは、色の数色の種類が足りないんじゃないの？」

→ **指摘は正しい。** 段ごとの色の数とクリア率が対応していた（色が多い XL・XXL だけが目安 30〜50% に入った）。わくに置いた箱は「自分の色がふちに出ていないと待つ」ので、色が 4 つしかないと わく 3 つで絵の色をほぼ覆ってしまい、必ず何かが運べる＝詰まらない。**効いていたのは わくの数ではなく「色の数 ÷ わくの数」。** 実際の絵の色数：4 色 4 枚・5 色 11 枚・6 色 4 枚・7 色 14 枚・8 色 9 枚・9 色 5 枚・10 色 1 枚。

### ユーザーの決定（そのまま。2026-10-29）

「色水はめっちゃ面白い。色水が面白いのは多分クリアできるまで何度でもトライ。手軽にリトライできるからだと思う。やっぱりリトライの数っていうのは無限にあってもいいと思うんだけど、砂糖の色の数色の種類これはちょっと増やしたほうがいいと思うな。」

決定：
1. **1手もどす・やりなおしは無限のまま**（いろびんと同じ手軽さ）。段 0 の `UNDO_MAX = 3` は**取り消す**。前の決定「手詰まりは面のやり直し」も、無限にやり直せる形に戻す。
2. **砂糖の色の数・種類を増やす**（緊張の源はこれ）。
3. **わくは 3 のまま**（1・2 面の保証 100%・1 面の長さが目安内）。

### 狙う形（判定の目安を書き換え）

- でたらめに押すと**詰まる**（7 割でたらめのクリア率 30〜50%）

- やり直しは軽い（無限）。**砂糖もアリも最後は必ず両方 0 になり、絵が完成する**（§1.6・`won: left === 0` は不変）
- 1 面の長さ 45〜120 秒。1・2 面はどう押してもクリアできる
