## 6. 作業環境のこと

### クラウド

- 4コアなので、同時に動くサブエージェントは実質2人。テストは担当ごとに `PORT` を分ける。WebKit は `WORKERS=1`。
- 環境のセットアップスクリプトは `node "$(npm root -g)/playwright/cli.js" install --with-deps webkit` に直してある。`create_session` で別のクラウドセッションを立ててテストを並列に流せる（10/19 に起動を確認）。
- クラウドから github.io は開けない（プロキシで拒否）。公開の反映は、GitHub の Pages の Actions の実行結果か、ユーザーの実機で確かめる。

### 自宅 PC（Windows、6コア12スレッド、16GB）

- リポジトリは `C:\tools\vm\share\701．ゆびあそび\game-no1`。作業前に `git switch master` と `git pull origin master`。
- 確認の許可リスト（`.claude/settings.local.json`）はクラウドからは入れられない。ユーザーが PC の Claude Code で作る（`git push` は確認を残す）。

### iPhone の実機デバッグ

- Mac が無いので、PC から iPhone をタップする方法は無い（WebDriverAgent に Mac が要る）。
- 画面の撮影は pymobiledevice3（未検証）か AirPlay の受信ソフト。当面は `?debug=1` とスクリーンショット・画面収録で行う。
