## 5. 決めごとの要点（詳しくは CLAUDE.md）

- 公開はユーザーの「公開して」のあとだけ。版は `common/version.js` の version・date と `sw.js` の `CACHE_VERSION` を一緒に（日付は公開する日）。
- 関門：Chromium の smoke と full、WebKit の smoke（`HEADED=1 BROWSER=webkit WORKERS=1 xvfb-run -a`）。WW10 は単独で合格なら可（基準 10%）。変異テストは仕組みを変えたときだけ、そのゲームの関わる分を ONLY と M で絞って流す（全部を流すと 10 分を超えて止まる）。
- 進め方：Opus が計画 → Sonnet・Haiku が小さなタスク → Opus が確かめる → レビュー（直しは技術＋UX、遊びが変わるときは＋中毒性）→ 指摘を直してコミット → 版上げ・関門 → 公開。
- 公開は fast-forward の push（`git push origin <作業ブランチ>:master`）。force push・履歴の書き換えはしない。PR はユーザーが頼んだときだけ。
- 答え方：日本語・初級者向け・おすすめ 1 つ・「事実に基づいて回答します」「以下は私の推測です」の前置き・改善は 4 段（直接・根本・直近・中長期）。
