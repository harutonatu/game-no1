## 2. この会話でやったこと（2026-10-19〜20）

### v22（いろびんの布の瓶・ブロックの修正）
- **いろびん：布の瓶**（約束 §17）。お客さんに決まった人数を届けると布が取れる。中身は色水か空き瓶。
  - ユーザー決定：「布の瓶、中身が入っている、空き瓶がランダムで出てくる、両方採用します。…」「単に色水が入っている（空き瓶ではない）」という意味です。今までなかった新しい色ではないです」
  - 考えどころを強めた（§17.9、ユーザー決定「考えどころを強める」）：8面の布は必ず色水入り・あと1にん、15〜24面は空き瓶の布 4割、25面以降は1面おきに色水入りの布（9色で あと4〜6にん）で、布の色のお客さんが先に来る面を選ぶ。
- **いろびん：届けた瓶の跡は空いたまま**（§17.7）。ユーザー決定：「あと瓶の位置ですが、今は便が消えると位置を調整してくれる機能があります。あれは外してください。」。瓶の番号は置き場所で固定。
- いろびんの保存の形は v:3（前の版の途中保存は面の最初から）。
- **ブロック：低い横画面でスコア欄と DROP が重なる**のを直した（X-16）。フォントで行の高さが変わるのが原因。行の高さを px で固定。

### v23（まとめてポン）
- **さめがめ風の新しいゲーム**。ユーザー決定：名前「まとめてポン」、操作「2回タップで消す」、盤「１０×２０ではどうでしょう？縦長に合わせる形です」、空いた列は「左へ詰まるのを残す案でお願いします」。
- モード：やさしい（3色、ユーザー決定）・ふつう（4色）・むずかしい（5色）。(n−2)² 点、全部消し +1000、1手もどす何回でも、途中保存。
- **まわりも消える**（約束 §10）：ユーザー決定「aとcを採用します。エフェクトも少し派手めに。…上下左右　cは3回続けて消すと、同時消し範囲が広がる」→「７個以上を５個以上にしましょう。」→「…１こにつき、＋３点にしましょう」。
  - いま：**5こ以上**消すと上下左右1マスのまわりも消える。5こ以上を**3回続けると2マス**に広がる（4こ以下で回数は0）。まわり1こ **+3点**。保存の形 v:3。

## 7. この会話で学んだこと（進め方）

- 仕様を変えるときは、**約束の文書に章を足してから**担当に渡す（いろびん §17.7〜17.9、まとめてポン §8〜§10）。ユーザーの言葉をそのまま引用する。
- 同じファイルを2人の担当に同時に触らせない。後からの決定は SendMessage で作業中の担当に伝える。
- レビュー（技術・UX・中毒性と品質）は**作った直後に1回**。中毒性・品質の担当は Node で自動プレイを回して数字を出すと、判断が速い（布の瓶が考えどころとして効いていない、点数が下がる、などはここで分かった）。
- 公開は「関門合格 → ユーザーに結果を見せて承認 →（Haiku が）fast-forward の push → PM が origin/master と版を確かめる」。v22・v23 ともこの順で問題なし。
- 公開済みの master を作業ブランチに取り込むと、tests/README.md・tests/design.md・tests/mutants/mutate.mjs・common/sfx.js の追記どうしがぶつかる。両方の追記を残せばよい。
